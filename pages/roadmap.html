초급자 추천 경로

SAP 개발을 처음 배우는 학습자를 위한 순서이다.

  1. 1
    SAP 개발자 학습 로드맵

    ABAP, UI5, Fiori Elements, 모듈 기초까지 전체 학습 순서를 안내한다.

  2. 2
    SAP 개발 환경과 도구 입문

    SAP GUI, ADT, VS Code/BAS, Gateway Client, Browser DevTools의 사용 목적을 정리한다.

  3. 3
    SAP 모듈 기초와 개발자 관점

    MM, PP, SD, FI, CO가 어떤 업무를 다루고 개발자가 왜 알아야 하는지 설명한다.

  4. 4
    Classic ABAP 기본기

    Report, Selection Screen, Internal Table, Open SQL, ALV의 기본 흐름을 익힌다.

  5. 5
    UI5 Controller 함수 문법 입문

    View와 Controller, 이벤트 핸들러, this/byId 기본 패턴을 익힌다.

  6. 6
    CDS View에서 OData 노출까지

    ZI_* Interface View, ZC_* Projection View, Association, Service Binding 흐름을 학습한다.

  7. 7
    Gateway / OData V2 CRUD 입문

    SEGW, EntitySet, MPC/DPC, CRUD 메서드와 테스트 흐름을 이해한다.

모듈/테이블 이해 경로

개발 요구사항을 업무 프로세스와 테이블 구조로 이해하려는 학습자를 위한 순서이다.

  1. 1
    SAP 모듈 기초와 개발자 관점

    MM, PP, SD, FI, CO가 어떤 업무를 다루고 개발자가 왜 알아야 하는지 설명한다.

  2. 2
    SAP Standard Table Map 입문

    Header/Item 구조, Document Flow, 주요 모듈 테이블을 지도처럼 정리한다.

  3. 3
    MM 프로세스와 주요 테이블 입문

    구매요청, 구매오더, 입고, 송장 검증과 주요 테이블을 이해한다.

  4. 4
    PP 프로세스와 주요 테이블 입문

    BOM, Routing, MRP, 생산오더, ATP/안전재고를 생산계획 흐름으로 연결한다.

  5. 5
    SD 프로세스와 주요 테이블 입문

    판매오더, 납품, 출고, 청구와 문서 흐름을 개발자 관점에서 이해한다.

  6. 6
    FI 프로세스와 주요 테이블 입문

    G/L 계정, 회계 전표, 번호범위, ACDOCA 중심의 FI 기본 구조를 이해한다.

  7. 7
    CO 프로세스와 주요 테이블 입문

    원가센터, 내부오더, 손익센터와 비용 흐름을 개발자 관점으로 이해한다.
