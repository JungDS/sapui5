SAP Flight Model 데이터 구조 해설

Flight 모델은 SAP 학습에서 자주 쓰는 표준 예제 데이터이다. 이 문서는 SCARR, SPFLI, SFLIGHT, SBOOK, SCUSTOM의 관계를 먼저 이해한 뒤 ABAP, Gateway, UI5, RAP 실습으로 넘어갈 수 있도록 정리한다.

Stage 7 통합 실습 Flight Model 배포자: 정훈영
01 · 목적

Flight 모델은 개발 흐름을 설명하기 좋은 작은 업무 도메인입니다

초급자는 ABAP 문법, OData 서비스, UI5 화면을 각각 따로 배우기 쉽다. 하지만 실무 개발은 하나의 업무 데이터를 여러 계층에서 다루는 일이다. Flight 모델은 항공사, 노선, 운항, 예약이라는 관계가 비교적 단순해서 데이터 모델과 화면 흐름을 함께 설명하기 좋다.

이 문서를 먼저 읽으면 이후 ClassRun, Gateway CRUD, UI5 ODataModel, RAP BO 실습에서 "지금 어떤 데이터를 다루고 있는지"를 놓치지 않을 수 있다.

02 · 주요 테이블

Flight 모델은 항공사에서 예약까지 이어지는 계층 구조입니다

테이블 의미 주요 Key 학습 포인트
SCARR 항공사 마스터 CARRID 최상위 기준 데이터이다.
SPFLI 항공사별 노선 CARRID, CONNID 출발/도착 도시와 노선 정보를 가진다.
SFLIGHT 날짜별 운항 CARRID, CONNID, FLDATE 가격, 좌석 수, 예약 좌석 수를 확인한다.
SBOOK 예약 상세 CARRID, CONNID, FLDATE, BOOKID 특정 운항에 연결된 예약 데이터를 다룬다.
SCUSTOM 고객 마스터 ID 예약 고객 정보를 연결할 때 사용한다.
03 · 관계

관계는 항공사 → 노선 → 운항 → 예약 순서로 읽습니다

SCARR → SPFLI

하나의 항공사는 여러 노선을 가진다. CARRID가 연결 기준이다.

SPFLI → SFLIGHT

하나의 노선은 여러 날짜의 운항으로 확장된다. CARRID, CONNID가 이어진다.

SFLIGHT → SBOOK

하나의 운항에는 여러 예약이 붙는다. 날짜까지 포함한 Key가 중요하다.

SBOOK → SCUSTOM

예약의 고객 번호를 통해 고객 마스터를 읽는다. 화면에서는 고객명 표시나 필터에 활용할 수 있다.

04 · 조회 연습

처음에는 한 단계씩 JOIN 범위를 넓힙니다

  1. SCARR만 조회해서 항공사 목록을 확인한다.
  2. SPFLI를 붙여 항공사별 노선 수를 확인한다.
  3. SFLIGHT를 붙여 날짜별 운항과 좌석 정보를 확인한다.
  4. SBOOK을 붙여 예약 건수 또는 예약 금액을 집계한다.
관계 확인용 Open SQL 예시
SELECT FROM scarr AS carrier
  INNER JOIN spfli AS route
    ON route~carrid = carrier~carrid
  INNER JOIN sflight AS flight
    ON flight~carrid = route~carrid
   AND flight~connid = route~connid
  FIELDS carrier~carrid,
         carrier~carrname,
         route~connid,
         flight~fldate,
         flight~seatsmax,
         flight~seatsocc
  INTO TABLE @DATA(lt_flights).
05 · 체크리스트

통합 실습 전 다음을 설명할 수 있어야 합니다

  • SCARR, SPFLI, SFLIGHT, SBOOK의 역할을 구분할 수 있다.
  • CARRID, CONNID, FLDATE가 왜 함께 쓰이는지 설명할 수 있다.
  • 목록 화면에는 어떤 필드가 필요하고, 상세 화면에는 어떤 필드가 필요한지 나눌 수 있다.
  • Gateway EntitySet 또는 RAP Entity를 만들 때 어떤 테이블을 기준으로 삼을지 판단할 수 있다.
주의 Flight 모델은 학습용 예제이다. 실무 테이블처럼 모든 업무 규칙이 완전하게 들어 있는 모델은 아니므로, 구조 학습과 계층 연결 연습에 초점을 맞춘다.
