Fiori Launchpad 배포와 Semantic Object 입문

Fiori Launchpad는 사용자가 앱을 찾고 실행하는入口다. 개발자는 앱 배포뿐 아니라 Tile, Target Mapping, Semantic Object, 권한 연결을 함께 이해해야 한다.

Stage 7 Docs FLP Deployment 배포자: 정훈영
01 · 역할

Fiori Launchpad는 사용자가 앱을 실행하는 출발점입니다

SAPUI5 앱을 개발 서버에서 실행하는 것과 실제 사용자가 Launchpad에서 실행하는 것은 다르다. 운영 환경에서는 앱 리소스가 SAP 시스템이나 HTML5 App Repository에 배포되고, 사용자는 Launchpad의 Tile 또는 링크를 통해 앱을 실행한다.

따라서 배포 작업은 파일 업로드만 의미하지 않는다. 사용자가 앱을 찾을 수 있는 Catalog, Space/Page, Target Mapping, 권한 Role까지 연결되어야 실제 운영 앱이 된다.

02 · Semantic Object

Semantic Object와 Action은 사용자의 의도를 표현합니다

Launchpad에서 앱 이동은 보통 #SemanticObject-action 형태의 intent로 표현된다. 예를 들어 판매오더 조회 앱은 #SalesOrder-display, 생성 앱은 #SalesOrder-create처럼 정의할 수 있다.

항목의미
Semantic Object업무 대상이다. 예: SalesOrder, PurchaseOrder, Material
Action대상에 대해 수행할 의도다. 예: display, create, manage
Target MappingIntent를 실제 앱 URL, Component, Parameter와 연결한다.
Tile사용자가 Launchpad에서 누르는 진입점이다.
03 · 배포 흐름

배포 후에는 앱 실행 경로와 권한을 함께 확인합니다

  1. UI5 앱을 빌드하고 배포 대상 시스템에 업로드한다.
  2. 앱 ID, Component ID, 리소스 경로가 manifest와 일치하는지 확인한다.
  3. Semantic Object와 Action을 정의한다.
  4. Target Mapping을 만들어 Intent와 앱을 연결한다.
  5. Catalog와 Space/Page 또는 Group에 Tile을 배치한다.
  6. 사용자 Role에 필요한 Catalog 권한이 포함되어 있는지 확인한다.
04 · 흔한 오류

배포 오류는 앱 코드보다 Launchpad 설정에서 자주 발생합니다

  • Tile은 보이지만 실행되지 않으면 Target Mapping과 Component ID를 확인한다.
  • 개발자는 보이는데 사용자에게 보이지 않으면 Role과 Catalog 권한을 확인한다.
  • 앱이 열리지만 리소스가 404이면 배포 경로와 manifest의 앱 ID를 확인한다.
  • Semantic Object 이름은 업무 대상 기준으로 일관되게 정한다.
05 · 완료 체크

FLP 배포 기본기를 다음 항목으로 확인합니다

  1. Tile과 Target Mapping의 차이를 설명한다.
  2. Semantic Object와 Action이 Intent를 만든다는 점을 설명한다.
  3. 앱 배포 후 권한 Role 확인이 필요한 이유를 설명한다.
  4. Tile은 보이지만 앱이 열리지 않을 때 확인할 지점을 말할 수 있다.
