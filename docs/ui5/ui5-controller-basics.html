UI5 Controller 함수 문법 입문

는 XML View에서 발생한 사용자 행동을 받아 모델을 읽고, 화면 상태를 바꾸고, 라우팅이나 저장 같은 앱 동작을 실행하는 위치다.

Stage 7 Docs Freestyle SAPUI5 Controller
01 · 역할

는 화면의 행동을 담당합니다

에서 View는 화면 구조를 선언하고, 는 사용자가 클릭하거나 값을 바꾸었을 때 어떤 처리를 할지 정의한다. 초급자는 를 "버튼 함수 모음"으로만 이해하기 쉽지만, 실무에서는 View, Model, Router, MessageManager를 연결하는 중심 지점이다.

에 모든 업무 로직을 넣는 것은 좋지 않다. 는 화면 이벤트를 받아 필요한 서비스나 모델 호출로 넘기는 조정자 역할에 가깝다.

02 · 기본 모양

파일은 define과 extend 구조로 작성합니다

sap.ui.define([
  "sap/ui/core/mvc/Controller",
  "sap/m/MessageToast"
], function (Controller, MessageToast) {
  "use strict";

  return Controller.extend("my.app.controller.List", {
    onInit: function () {
      // 초기화 로직
    },

    onPressSave: function () {
      MessageToast.show("저장합니다.");
    }
  });
});

sap.ui.define의 배열에는 필요한 모듈을 적고, 함수 인자에는 같은 순서로 받을 이름을 적는다. 순서가 틀리면 Controller는 로드되더라도 런타임에서 예상하지 못한 오류가 발생할 수 있다.

03 · 이벤트 연결

XML View의 이벤트 이름과 Controller 함수 이름이 연결됩니다

<Button
  text="저장"
  type="Emphasized"
  press=".onPressSave" />

XML View에서 press=".onPressSave"라고 쓰면, 현재 View에 연결된 Controller의 onPressSave 함수가 실행된다. 점 표기는 현재 Controller 안의 함수를 찾겠다는 의미로 이해하면 된다.

04 · this

Controller 안의 this는 현재 Controller 인스턴스를 가리킵니다

UI5 Controller 메서드 안에서 this는 보통 현재 Controller다. 그래서 this.getView(), this.byId(), this.getOwnerComponent() 같은 API를 사용할 수 있다. 

onPressShowName: function () {
  const oInput = this.byId("nameInput");
  const sName = oInput.getValue();
  MessageToast.show("입력값: " + sName);
}
주의 콜백 함수 안에서는 this가 바뀔 수 있다. 필요하면 .bind(this)를 사용하거나, 화살표 함수 사용 가능 여부를 프로젝트 기준에 맞춰 확인한다.
05 · 자주 쓰는 API

View, Model, Router 접근 패턴을 먼저 익힙니다

패턴의미
this.byId("id")현재 View 안의 컨트롤을 찾는다.
this.getView().getModel()현재 View에 연결된 기본 모델을 가져온다.
this.getView().getModel("view")이름 있는 모델을 가져온다.
this.getOwnerComponent().getRouter()앱 라우터를 가져온다.
06 · 완료 체크

Controller 기본기를 다음 항목으로 확인합니다

  1. XML View의 이벤트와 Controller 함수가 어떻게 연결되는지 설명한다.
  2. sap.ui.define의 배열과 함수 인자 순서가 중요하다는 점을 설명한다.
  3. this.byId, getView, getOwnerComponent의 용도를 구분한다.
  4. Controller에 모든 업무 로직을 몰아넣지 않아야 하는 이유를 설명한다.
