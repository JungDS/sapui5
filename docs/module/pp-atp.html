SAP ATP 학생 학습 패키지

재고와 가용수량의 차이, 판매오더에서 납기 약속이 판단되는 방식을 학습한다.

Stage 7SAP 모듈 기초PP
01 · 개념

업무 의미를 먼저 잡고 테이블을 읽습니다

재고와 가용수량의 차이, 판매오더에서 납기 약속이 판단되는 방식을 학습한다.

초급 개발자는 모듈 용어를 외우기보다 업무 흐름, 문서 구조, 주요 테이블이 어떻게 연결되는지 먼저 이해해야 한다.

02 · 업무 흐름

흐름을 단계로 나누면 개발 포인트가 보입니다

  1. 업무 문서가 생성되는 시작점을 확인한다.
  2. Header와 Item 구조를 구분한다.
  3. 후속 문서 또는 회계/재고 영향이 있는지 확인한다.
  4. 상태값, 조직값, 금액/수량 필드를 분리해서 본다.
  5. 화면 요구사항을 테이블, CDS View, API 후보로 나누어 정리한다.
03 · 주요 테이블

처음에는 기준 테이블과 의미를 함께 봅니다

대상역할개발자가 볼 점
MARD저장위치 재고현재 재고를 확인한다.
VBBE판매오더 요구량미충족 수요를 확인한다.
MD04Stock/Requirements List수요와 공급 요소를 화면에서 확인한다.
VBAP판매오더 Item요청 수량과 확인 수량을 비교한다.
MARC자재 플랜트 데이터ATP와 MRP 관련 설정을 확인한다.
04 · 개발자 관점

요구사항을 분석할 때 다음 순서로 확인합니다

  • 사용자가 말한 업무 단어를 모듈, 문서 유형, 기준 테이블로 바꿔 본다.
  • 직접 테이블 조회 전에 표준 CDS View나 공개 API가 있는지 확인한다.
  • 목록 화면, 상세 화면, 저장 처리에 필요한 필드를 나누어 정리한다.
학습 기준 모듈 문서는 업무 전문가가 되는 자료가 아니라, 개발자가 요구사항을 테이블과 서비스 구조로 번역하기 위한 출발점이다.
05 · 체크리스트

문서를 읽은 뒤 다음을 확인합니다

  • 이 문서의 업무 흐름을 3단계 이상으로 설명할 수 있다.
  • 주요 테이블과 개발자가 확인할 필드를 연결할 수 있다.
  • 실제 프로젝트에서는 회사별 설정과 확장 필드를 추가로 확인해야 함을 이해한다.
주의 표준 테이블 구조는 시스템 버전과 회사 설정에 따라 다르게 보일 수 있다. 운영 개발에서는 권한, 성능, 공개 API 제공 여부를 함께 검토한다.
