ABAP New Syntax 입문

DATA(...), VALUE, CORRESPONDING, FOR, inline declaration, table expression을 실무 코드 독해 관점에서 정리한다.

Stage 7ABAP 개발New Syntax배포자: 정훈영
01 · 목적

New Syntax는 짧게 쓰기 위한 문법이 아니라 의도를 드러내기 위한 문법입니다

현대 ABAP 코드는 선언 위치를 사용 위치 가까이에 두고, 테이블 변환과 구조 매핑을 표현식으로 처리한다. 초급자는 문법 이름보다 이 코드가 데이터를 새로 만드는지, 기존 데이터를 변환하는지, 일부 필드만 옮기는지를 먼저 읽어야 한다.

실무 기준 New Syntax는 코드량을 줄이지만, 과도하게 중첩하면 오히려 유지보수가 어려워진다. 교육용 코드는 명확성을 우선한다.
02 · 핵심 문법

초급자는 5가지 패턴부터 익히면 대부분의 코드를 읽을 수 있습니다

DATA(...)

타입을 컴파일러가 추론해 변수 선언을 줄인다. 조회 결과나 메서드 반환값을 받을 때 자주 사용한다.

VALUE #( )

구조나 내부 테이블 값을 한 번에 만든다. 테스트 데이터, 반환 구조, 메시지 목록 구성에 유용하다.

CORRESPONDING #( )

동일한 이름의 필드를 기준으로 구조를 매핑한다. Projection 구조나 DTO 변환에서 자주 등장한다.

FOR ... IN

내부 테이블을 반복하면서 새로운 내부 테이블을 구성한다. 단순 변환에는 LOOP보다 의도가 선명하다.

03 · 예제

기존 LOOP 변환을 표현식 기반으로 바꿀 수 있습니다

SELECT carrid, connid, fldate, price, currency
  FROM sflight
  WHERE carrid = @p_carrid
  INTO TABLE @DATA(lt_flight).

DATA(lt_result) = VALUE tt_result(
  FOR ls_flight IN lt_flight
  ( carrid   = ls_flight-carrid
    connid   = ls_flight-connid
    fldate   = ls_flight-fldate
    amount   = ls_flight-price
    currency = ls_flight-currency ) ).

이 코드는 조회 결과를 화면 출력용 구조로 변환한다. LOOP로 작성해도 되지만, 단순 변환은 VALUE와 FOR를 사용하면 결과 테이블을 만든다는 의도가 더 분명해진다.

04 · 주의점

짧은 코드가 항상 좋은 코드는 아닙니다

  • 중첩 FOR와 COND를 과도하게 섞지 않는다.
  • 예외 처리가 필요한 로직은 단계적으로 나누어 읽기 쉽게 작성한다.
  • CORRESPONDING은 필드명이 같을 때만 안전하므로 매핑 누락을 확인한다.
  • 학생 교육용 예제에서는 최신 문법과 전통 문법을 함께 보여준다.
05 · 완료 체크

다음 단계로 가기 전 확인합니다

  1. DATA(...)의 타입 추론 의미를 설명할 수 있다.
  2. VALUE #( )로 구조와 내부 테이블을 만들 수 있다.
  3. CORRESPONDING #( )의 장점과 위험을 구분할 수 있다.
  4. FOR 표현식과 LOOP의 사용 기준을 설명할 수 있다.
