학습 목표

표에서 중요한 값을 눈에 띄게 하는 색상을 배웁니다. 컬럼 전체에 색을 주는 EMPHASIZE와, 행마다 색을 다르게 하는 행 색상(INFO_FNAME)의 기초를 익히며 Grid ALV Chapter를 마무리합니다.

1. 지난 시간 연결: 숫자만으론 안 보인다 🌈

표가 길고 숫자가 많으면, 정작 중요한 값(마이너스 금액, 마감 임박 건 등)이 묻혀버립니다. 이럴 때 색상으로 강조하면 사용자가 한눈에 알아챕니다.

색을 주는 방법은 크게 두 가지입니다. 컬럼 단위와 행 단위입니다.

2. 컬럼 색상 — Field Catalog의 EMPHASIZE ✍️

특정 컬럼 전체에 색을 주려면 Field Catalog(M04)의 emphasize 항목에 색상 코드를 넣습니다.

ABAP
1
2
3
4 
gs_fcat-fieldname = 'PRICE'.
gs_fcat-coltext   = '요금'.
gs_fcat-emphasize = 'C610'.   "색상 코드 (C + 색번호 + 강도 + 반전)

APPEND gs_fcat TO gt_fcat.
💡

색상 코드 읽는 법 (Cxyz)

  • C: 색상이라는 표시(Color).
  • x(1~7): 색 번호(예: 5=초록, 6=빨강 계열).
  • y(0/1): 강도(intensified).
  • z(0/1): 반전(inverse).

3. 행 색상 — Layout의 INFO_FNAME 🎨

4. 정상 흐름과 오류 흐름 🔍

  • ✅ 정상: 컬럼은 emphasize로, 행은 색상 필드 + info_fname으로 강조됩니다.
  • ❌ 오류 1: info_fname에 적은 필드가 출력 테이블에 없음 → 행 색상이 동작 안 함(M05 주의 그대로).
  • ❌ 오류 2: 색을 너무 많이 써서 표가 알록달록 → 오히려 무엇이 중요한지 안 보임.
참고로 셀(칸) 하나하나에 색을 주는 더 세밀한 방법(Cell Color)도 있는데, 이는 Deep Structure를 쓰며 THEORY-19에서 다룹니다. 이번엔 컬럼·행 단위까지만.

5. 실무에서 조심할 점 🚨

⚠️

색은 "의미"를 담을 때만

색상은 "예뻐서"가 아니라 "의미를 전달할 때" 써야 합니다. 빨강=경고/마이너스, 초록=정상처럼 일관된 규칙을 정하고, 한 화면에 색은 2~3종류로 절제하세요. 또 색맹 사용자를 위해 색에만 의존하지 말고, 아이콘이나 텍스트로도 함께 표시하는 것이 좋은 접근성입니다.

THEORY-15 마무리 핵심

  • Grid ALV: Container → Grid → (데이터·Field Catalog·Layout) → first_display의 흐름.
  • 갱신은 refresh(is_stable)로 위치를 유지하며 다시 그립니다.
  • 컬럼 색은 Field Catalog의 emphasize, 행 색은 색상 필드 + Layout의 info_fname.
  • 색은 의미를 담아 절제해서 사용합니다.
