학습 목표

이번 Lesson에서는 값을 화면에 찍는 가장 기본 도구 WRITE를 제대로 다룹니다. 결과가 표시되는 Output List의 개념과, 줄 바꿈·정렬·자리수 같은 기본 서식(Formatting)을 익혀 보기 좋은 출력을 만듭니다.

1. 지난 Lesson 연결: 값을 담았으니 이제 보여 주자

지난 Lesson에서 DATA·CONSTANTS·TYPES로 값을 담는 법을 배웠습니다. 이제 그 값이 “정말 내가 의도한 값인지” 눈으로 확인할 차례입니다. 가장 간단한 확인 방법이 WRITE로 결과 화면에 찍어 보는 것입니다.

WRITE는 화려한 화면 도구는 아니지만, 초심자가 “값이 어떻게 흘러가는지”를 즉시 확인하는 데 가장 빠른 도구입니다. 디버깅 감각을 키우는 첫 단추이기도 합니다.

오늘의 목표: 값을 그냥 찍는 것을 넘어, 줄을 바꾸고 정렬해 “읽을 수 있는 출력”을 만드는 것.

2. WRITE와 Output List: 결과는 어디에 찍히나

WRITE를 실행하면 그 값은 Output List(기본 출력 목록)라는 결과 화면에 한 항목씩 쌓입니다. 프로그램을 실행(F8)하면 SAP GUI가 이 목록을 새 화면으로 보여 줍니다.

WRITE 여러 개는 자동으로 줄이 바뀌지 않습니다

위 코드는 Hello ABAP처럼 한 줄에 이어서 출력됩니다. WRITE는 기본적으로 “같은 줄에 이어 쓰기”이기 때문입니다. 줄을 바꾸려면 줄 바꿈 기호 /를 써야 합니다.

3. 줄 바꿈과 묶음 출력: 슬래시(/)와 콜론(:)

줄을 바꾸려면 값 앞에 /를 둡니다. 또 같은 문장을 반복하기 싫을 때는 콜론(:)과 쉼표로 여러 항목을 한 번에 쓸 수 있습니다(체인 문장).

출력 기호 3가지

기호뜻예
WRITE x.같은 줄에 이어 출력Hello ABAP
WRITE / x.새 줄에서 출력줄을 바꿔 출력
WRITE: a, b.한 문장으로 여러 항목(체인)WRITE 반복 생략

콜론 체인은 WRITE를 한 번만 쓰고 항목을 쉼표로 나열한 뒤 마지막에 마침표로 닫습니다.

4. 기본 서식: 자리수 · 정렬 · 날짜/통화

서식(Formatting) 옵션을 붙이면 숫자 자리수, 정렬, 날짜·통화 형식을 다듬을 수 있습니다. 처음에는 자주 쓰는 몇 가지만 알아도 충분합니다.

자주 쓰는 WRITE 서식 옵션

옵션역할
... LEFT-JUSTIFIED왼쪽 정렬
... RIGHT-JUSTIFIED오른쪽 정렬(숫자 가독성)
... NO-ZERO앞쪽 0을 공백으로
... DD/MM/YYYY날짜 표시 형식 지정
... CURRENCY w통화 기준으로 소수 자리 맞춤

금액·통화 출력은 통화 키에 따라 소수 자리가 달라지므로(예: JPY는 소수 없음) CURRENCY 옵션으로 맞추는 것이 안전합니다.

왜 출력 형식까지 신경 써야 할까?

리포트는 사람이 읽습니다. 숫자가 왼쪽으로 들쭉날쭉 정렬되거나 통화 소수 자리가 틀리면, 코드가 “돌아가도” 보고서로는 신뢰를 잃습니다. 서식은 사소해 보여도 업무 산출물의 품질입니다.

5. 정상 흐름과 오류/혼동 흐름을 함께 보기

의도한 출력 vs 자주 하는 실수

❌ 자주 하는 실수
  • WRITE a. WRITE b. → 줄이 안 바뀌어 한 줄에 붙음.
  • 슬래시를 빼서 모든 값이 이어 붙음.
  • 금액을 WRITE 기본값으로 찍어 소수·통화가 어긋남.
✅ 의도한 출력
  • WRITE: / a, / b. → 줄을 나눠 출력.
  • 라벨과 값을 짝지어 읽기 쉽게 배치.
  • 금액은 CURRENCY로 자리수를 맞춤.

대부분의 “출력이 이상해요”는 문법 오류가 아니라 줄 바꿈·정렬·서식을 안 챙겨서 생깁니다.

6. 미니 실습: 읽기 좋은 결과 한 장 만들기

✍️

실습 과제

  1. 이름(string)과 수량(i) 변수를 선언하고 값을 넣습니다.
  2. 처음에는 WRITE 두 개로 그냥 찍어 “한 줄에 붙는” 모습을 확인합니다. (혼동 케이스)
  3. 슬래시 /와 콜론 : 체인으로 라벨과 값을 줄 맞춰 다시 출력합니다.
  4. 수량을 RIGHT-JUSTIFIED로 정렬해 봅니다. (정상 결과)

완료 조건: “왜 줄이 안 바뀌는지”를 설명하고, 슬래시·콜론·정렬 옵션으로 읽기 좋은 출력을 만들 수 있으면 성공입니다.

7. 실무에서 조심해야 할 점

🚨

WRITE 리스트는 “연습·디버깅용”이라는 점을 기억하세요

WRITE 기본 목록은 배우고 값을 확인하기엔 최고지만, 실무 보고서는 보통 ALV(뒤 Chapter)로 만듭니다. 정렬·필터·다운로드가 필요한 결과를 WRITE로 억지로 만들지 않습니다.

  • 표준 vs 커스텀: WRITE·서식 옵션 동작은 SAP 표준입니다. 사내 리포트 양식은 별도 관행으로 구분합니다.
  • 통화·날짜는 형식 지정: 사용자/통화에 따라 표시가 달라지므로 CURRENCY·날짜 형식을 명시합니다.
  • 과확장 금지: ALV·화면 출력은 뒤에서 다룹니다. 지금은 WRITE 기본기에 집중합니다.

9. 확인 퀴즈

  1. WRITE a. WRITE b.는 왜 두 줄로 나뉘지 않나요?
  2. 새 줄에서 출력하려면 무엇을 붙이나요?
  3. WRITE를 한 번만 쓰고 여러 값을 출력하는 방법은?
  4. 금액·통화 값을 출력할 때 형식 옵션을 쓰는 이유는?
정답/해설 보기
  1. WRITE는 기본이 “같은 줄에 이어 쓰기”이기 때문입니다.
  2. 슬래시 /를 값 앞에 붙입니다.
  3. 콜론 체인: WRITE: a, b, c.처럼 쉼표로 나열합니다.
  4. 통화/사용자 설정에 따라 소수 자리·표시가 달라지므로, CURRENCY·날짜 형식으로 맞춰야 정확합니다.
