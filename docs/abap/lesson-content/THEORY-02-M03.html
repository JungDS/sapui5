학습 목표

이번 Lesson에서는 변수에 담은 값을 화면에 보여 줍니다. WRITE 문이 출력 리스트에 어떻게 출력되는지, 줄바꿈 /와 체이닝 :(콜론) 문법, 그리고 날짜·숫자·정렬 같은 기본 포맷을 직접 출력해 보며 익힙니다.

1. 지난 Lesson 연결: 그릇에 담았으니 이제 꺼내 보자

앞 Lesson에서 DATA로 변수를 만들고 값을 담았습니다. 그런데 값이 잘 들어갔는지 눈으로 확인하려면 화면에 출력해야 합니다. 가장 기본적인 출력 명령어가 바로 WRITE입니다.

오늘의 핵심 한 줄: “WRITE는 곧장 화면에 그리는 게 아니라, 출력 리스트에 쌓아 두면 마지막에 한꺼번에 보여 준다.”

2. WRITE와 출력 리스트(List Buffer)

WRITE는 실행 즉시 화면을 그리는 게 아닙니다. 먼저 메모리 안의 출력 리스트(List Buffer)에 글자를 차곡차곡 적어 둡니다. 그리고 메인 처리 블록(START-OF-SELECTION)이 끝나면, 런타임이 그 리스트를 읽어 클래식 리스트 화면으로 한 번에 보여 줍니다.

ABAP
1
2
3
4 
REPORT z_write_demo.

START-OF-SELECTION.
  WRITE 'Hello, ABAP!'.   " 출력 리스트에 한 줄 기록

WRITE가 화면에 나오기까지

1. WRITE 실행글자를 출력 리스트(버퍼)에 기록
2. 블록 종료START-OF-SELECTION이 끝남
3. 자동 렌더런타임이 리스트를 화면에 표시

3. 줄바꿈 / 와 체이닝 :

값을 여러 개 출력할 때 매번 WRITE를 다시 쓰면 번거롭습니다. 두 가지 문법이 도와줍니다.

두 기호의 역할

/ (슬래시)
뜻다음 줄 1열로 이동(줄바꿈)
없으면같은 줄에 이어서 출력
: (콜론)
뜻같은 명령(WRITE)을 한 번만 쓰고 쉼표로 나열
주의여러 값 나열 시 콜론 없이 쉼표만 쓰면 구문 오류
ABAP
1
2
3
4
5 
* 체이닝(:)으로 WRITE 한 번, 슬래시(/)로 줄바꿈
WRITE: / '이름:', lv_name,
       / '도시:', lv_city,
       / '수량:', lv_qty.
WRITE: / a, b. 와 WRITE / a. WRITE / b.는 같나요?

결과는 같습니다. 콜론(:)은 “같은 시작 명령을 반복하지 마라”는 축약일 뿐, 컴파일러는 내부적으로 개별 WRITE 문으로 풀어서 처리합니다. 다만 여러 값을 나열할 때는 콜론이 있어야 하고 항목은 쉼표로 구분합니다.

4. 위치와 포맷 다듬기

출력 위치와 모양도 지정할 수 있습니다. 시작 열과 길이는 WRITE AT /<위치>(<길이>) 형태로, 값의 모양은 여러 포맷 옵션으로 조절합니다.

자주 쓰는 WRITE 포맷 옵션

옵션효과
AT /10(8)다음 줄 10번째 열부터 8자리 길이로 출력
DD/MM/YY날짜 형식 지정(실제 일·월·년 순서는 사용자 설정에 따름)
LEFT-JUSTIFIED / RIGHT-JUSTIFIED / CENTERED정렬(문자는 기본 왼쪽, 숫자는 기본 오른쪽)
NO-ZERO값이 0이면 공백 출력, 앞의 의미 없는 0 제거
NO-GAP출력 뒤 공백을 붙이지 않음
COLOR COL_*색상 적용(COL_HEADING, COL_POSITIVE, COL_NEGATIVE 등)
CURRENCY / UNIT통화·수량 소수 단위를 규칙대로 포맷
USING EDIT MASK '__:__:__'지정한 템플릿 모양으로 변형(예: 시간 HH:MM:SS)

날짜·통화 포맷은 로그인 사용자의 설정/마스터 데이터에 영향을 받습니다. 같은 코드라도 사용자에 따라 2026.06.17·17/06/2026처럼 다르게 보일 수 있습니다.

5. 직접 해보기: WRITE 출력 미리보기

아래 sandbox는 SE38에서 WRITE가 출력 리스트에 기록되는 방식을 미리 보는 실습입니다. 같은 값이라도 / 줄바꿈, : 체이닝, NO-ZERO, AT 위치 지정을 어떻게 쓰느냐에 따라 화면 결과가 달라집니다.

T-Code: SE38 (ABAP Editor)
WRITE 출력 리스트 미리보기
버튼을 누르면 WRITE: / 로 만든 출력 리스트가 줄 단위로 표시됩니다.
슬래시(/)를 빼면 출력이 어떻게 달라지나요?

WRITE: '이름:', lv_name, '도시:', lv_city.처럼 / 없이 쓰면 모두 한 줄에 이어서 출력됩니다(이름: 정훈영 도시: 서울). 줄을 나누고 싶은 항목 앞에 /를 붙이세요.

NO-ZERO는 데이터 값을 바꾸나요?

아닙니다. NO-ZERO는 출력 모양만 바꿉니다. 예를 들어 lv_qty에 00123이 들어 있어도 출력 리스트에는 123처럼 보일 수 있지만, 메모리 안의 원본 값은 그대로 유지됩니다.

6. 실무에서 조심할 점

WRITE 초심자 3대 실수

① / 누락
증상여러 값이 한 줄에 붙어 출력·잘림
처방줄 나눌 항목 앞에 /
② 콜론 혼동
증상WRITE a, b. → 구문 오류
처방WRITE: a, b. (콜론 필수)
③ List vs ALV
증상정렬·필터가 필요한데 WRITE만 씀
처방표 형태·인터랙션은 ALV 사용
🚨

WRITE 리스트와 ALV는 쓰임이 다릅니다

클래식 WRITE 리스트는 한 레코드를 여러 줄에 자유롭게 그릴 수 있어 간단한 출력·로그에 좋습니다. 하지만 정렬·필터·합계 같은 상호작용이 필요하면 ALV(CL_SALV_TABLE 등)가 표준입니다. 지금은 WRITE로 출력의 기본 감각을 익히고, 표 형태 데이터는 뒤 Chapter에서 ALV로 배웁니다.

8. 확인 퀴즈

  1. WRITE는 실행 즉시 화면을 그리나요, 아니면 어딘가에 먼저 쌓이나요?
  2. 출력에서 다음 줄로 넘기려면 무엇을 붙이나요?
  3. WRITE lv_a, lv_b.는 왜 오류가 날까요? 어떻게 고치나요?
  4. 숫자 필드가 0일 때 0 대신 공백을 출력하는 옵션은 무엇인가요?
  5. 정렬·필터·합계가 필요한 표 출력에는 WRITE 대신 무엇을 쓰나요?
정답/해설 보기
  1. 먼저 출력 리스트(List Buffer)에 쌓입니다. 처리 블록이 끝난 뒤 런타임이 한꺼번에 화면에 보여 줍니다.
  2. 슬래시 /를 항목 앞에 붙입니다. 다음 줄 1열로 이동합니다.
  3. 여러 값을 나열하려면 콜론이 필요합니다. WRITE: lv_a, lv_b.로 고칩니다.
  4. NO-ZERO입니다.
  5. ALV(예: CL_SALV_TABLE)입니다. 정렬·필터·집계를 표준으로 제공합니다.
