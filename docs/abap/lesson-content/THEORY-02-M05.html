학습 목표

이번 Lesson에서는 같은 작업을 여러 번 반복하는 방법을 배웁니다. 정해진 횟수만큼 도는 DO, 조건이 참인 동안 도는 WHILE, 그리고 반복 중 빠져나오는 EXIT와 건너뛰는 CONTINUE를 익힙니다.

1. 지난 Lesson 연결: 한 번이 아니라 여러 번 처리하기

조건 분기로 “언제 무엇을” 할지는 정했습니다. 그런데 업무는 “같은 일을 여러 번” 해야 할 때가 많습니다. 1번부터 10번까지 출력하기, 목록을 끝까지 훑기처럼요. 이때 쓰는 것이 반복문입니다.

핵심 질문: “반복 횟수를 미리 아는가(→ DO), 아니면 조건이 끝날 때까지인가(→ WHILE)?”

2. DO: 정해진 횟수만큼 반복

DO n TIMES.는 블록을 n번 반복하고 ENDDO로 닫습니다. 지금 몇 번째인지는 시스템 필드 sy-index가 알려 줍니다.

ABAP
1
2
3
4
5 
REPORT zdo_demo.

DO 3 TIMES.
  WRITE: / '반복 회차:', sy-index.
ENDDO.
💡

sy-index는 “지금 몇 바퀴째인지”

반복문 안에서 sy-index는 1부터 시작해 회차마다 1씩 늘어납니다. 중첩 반복에서는 안쪽 루프에 들어가는 순간 sy-index가 다시 1로 초기화되므로, 바깥 회차를 기억하려면 안쪽 루프 전에 DATA(lv_outer) = sy-index.처럼 따로 백업해 둬야 합니다.

3. WHILE: 조건이 참인 동안 반복

횟수를 미리 모르고 “어떤 조건이 만족될 때까지” 돌려야 하면 WHILE 조건. … ENDWHILE.를 씁니다. 조건이 거짓이 되는 순간 반복이 멈춥니다.

ABAP
1
2
3
4
5
6
7
8 
REPORT zwhile_demo.

DATA lv_i TYPE i VALUE 1.

WHILE lv_i <= 3.
  WRITE: / '값:', lv_i.
  lv_i = lv_i + 1.       " 조건을 바꾸는 줄이 반드시 필요
ENDWHILE.
⚠️

조건을 바꾸지 않으면 무한 루프

WHILE 안에서 조건에 쓰인 값을 바꿔 주지 않으면 영원히 참이라 프로그램이 멈추지 않습니다(무한 루프). 위 코드의 lv_i = lv_i + 1.처럼 “언젠가 조건을 거짓으로 만드는 줄”이 꼭 있어야 합니다.

4. EXIT와 CONTINUE: 빠져나오기와 건너뛰기

반복 도중 흐름을 조절하는 두 명령이 있습니다. EXIT는 루프를 즉시 끝내고, CONTINUE는 이번 회차의 남은 코드를 건너뛰고 다음 회차로 갑니다.

EXIT vs CONTINUE

EXIT
동작루프 전체를 즉시 종료
이후반복문 다음 줄로 이동
비유찾던 걸 찾으면 방을 나감
CONTINUE
동작이번 회차 남은 코드 건너뜀
이후같은 루프의 다음 회차로
비유이번 사람만 통과, 줄은 계속
ABAP

REPORT zexit_continue.

DO 5 TIMES.
  IF sy-index = 3.
    CONTINUE.            " 3회차는 건너뛰고 다음으로
  ENDIF.
  IF sy-index = 5.
    EXIT.                " 5회차에서 루프 종료
  ENDIF.
  WRITE: / sy-index.
ENDDO.
" 출력: 1, 2, 4

5. 정상 흐름과 오류 흐름을 함께 보기

반복문에서 자주 만나는 상황

WHILE 조건lv_i <= 3
증가lv_i = lv_i + 1
종료OK 조건 거짓 → 멈춤
WHILE 조건lv_i <= 3
증가 줄 없음조건이 영원히 참
결과무한 루프 프로그램 멈춤/타임아웃
DO 시작DO 3 TIMES.
ENDDO 누락블록을 닫지 않음
활성화실패 문법 오류

무한 루프는 문법 오류가 아니라 “논리 오류”라 활성화는 통과합니다. 그대로 실행하면 시간 제한을 넘겨 TIME_OUT 런타임 덤프가 납니다. 실행이 안 끝나면 가장 먼저 반복 조건을 의심하세요.

6. 미니 실습: 1~10 중 짝수만 출력하기

✍️

실습 과제

  1. DO 10 TIMES.로 1부터 10까지 돌립니다(sy-index 활용).
  2. 홀수 회차는 CONTINUE로 건너뛰고 짝수만 출력합니다.
  3. WHILE로 같은 결과를 만들어 보고, 증가 줄을 일부러 빼서 무한 루프를 관찰합니다. (오류 케이스 — 실행 중지 방법도 메모)
  4. 증가 줄을 다시 넣어 정상 종료시킵니다. (정상 결과)

완료 조건: DO와 WHILE을 언제 쓰는지 구분하고, 무한 루프의 원인과 예방법을 설명할 수 있으면 성공입니다.

실습 중 무한 루프에 빠지면?

연습 시스템에서 무한 루프가 의심되면 보통 실행을 강제로 중단합니다(예: SAP GUI의 중지 또는 디버거 진입). 가장 중요한 것은 “WHILE 조건에 쓰인 값을 루프 안에서 바꾸고 있는가”를 확인하는 것입니다.

7. 실무에서 조심해야 할 점

🚨

반복 안에서 무거운 작업을 함부로 넣지 마세요

반복 횟수가 커지면, 루프 안의 한 줄이 성능을 좌우합니다. 특히 반복 안에서 데이터베이스를 매번 조회하는 패턴은 대표적인 안티패턴입니다(뒤 Chapter에서 자세히). 지금은 “루프 안은 가볍게”라는 감만 기억하세요.

  • 종료 조건 먼저: WHILE은 “언제 끝나는가”를 먼저 정하고 그 값을 루프 안에서 바꿉니다.
  • 표준 vs 커스텀: DO/WHILE/EXIT/CONTINUE 동작은 SAP 표준입니다. 반복 횟수·임계값 같은 업무 규칙은 별도로 기록합니다.
  • 과확장 금지: 내부 테이블을 훑는 LOOP AT은 테이블을 배운 뒤 다룹니다. 지금은 DO/WHILE 기본기에 집중합니다.
sy-index vs sy-tabix, 그리고 Modern 반복

회차 카운터는 반복문 종류에 따라 다릅니다. DO·WHILE은 sy-index, 내부 테이블을 훑는 LOOP AT은 sy-tabix(현재 행 번호)를 봅니다. 둘을 혼동하면 엉뚱한 인덱스를 읽어 버그가 됩니다. 한편 최신 ABAP에서는 대량 데이터를 다룰 때 DO/WHILE보다 FOR·REDUCE 같은 함수형 표현식을 권장합니다(뒤 Chapter).

8. 공식 문서로 더 확인하기

SAP Help Portal: DO횟수 기반 반복 DO ... ENDDO와 sy-index를 확인합니다. SAP Help Portal: WHILE조건 기반 반복 WHILE ... ENDWHILE을 확인합니다. SAP Help Portal: EXIT / CONTINUE반복 종료(EXIT)와 다음 회차로 건너뛰기(CONTINUE)를 확인합니다.

9. 확인 퀴즈

  1. 반복 횟수를 미리 아는 경우와 모르는 경우에 각각 어떤 문장을 쓰나요?
  2. 현재 반복 회차를 알려 주는 시스템 필드는 무엇인가요?
  3. EXIT와 CONTINUE의 차이는 무엇인가요?
  4. WHILE이 무한 루프에 빠지는 가장 흔한 원인은?
정답/해설 보기
  1. 아는 경우는 DO n TIMES, 모르는 경우는 WHILE 조건입니다.
  2. sy-index입니다(1부터 증가).
  3. EXIT는 루프 전체 종료, CONTINUE는 이번 회차만 건너뛰고 계속입니다.
  4. 조건에 쓰인 값을 루프 안에서 바꾸지 않아서입니다.

10. 한눈에 정리

DO정해진 횟수만큼 반복. sy-index로 회차 확인, ENDDO로 닫음.
WHILE조건이 참인 동안 반복. 조건 값을 꼭 바꿔 줘야 함.
EXIT루프를 즉시 종료하고 다음 줄로.
CONTINUE이번 회차만 건너뛰고 다음 회차로.
