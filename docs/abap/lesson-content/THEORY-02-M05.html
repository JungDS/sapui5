학습 목표

지난 Lesson에서 조건에 따라 다른 길로 가는 법을 배웠습니다. 이번에는 같은 일을 여러 번 반복하는 DO, WHILE, 반복을 끝내는 EXIT, 현재 회차를 건너뛰는 CONTINUE를 배웁니다.

1. 지난 시간 연결: 한 번 고른 길을 여러 번 반복하기 🔁

이전 Lesson의 조건문은 “이번에는 어떤 길로 갈까?”를 정했습니다. 반복문은 “이 일을 몇 번 할까?” 또는 “이 조건이 참인 동안 계속할까?”를 정합니다.

예를 들어 1부터 5까지 출력하거나, 어떤 값이 목표에 도달할 때까지 계속 계산하는 상황을 생각해볼 수 있습니다. 이런 반복을 손으로 5줄, 10줄 복사해서 쓰면 코드가 금방 지저분해집니다. 반복문은 같은 패턴을 깔끔하게 줄여줍니다.

2. DO: 정해진 횟수만큼 반복하기 🧮

DO는 반복 횟수를 정해두고 실행할 때 좋습니다. 가장 초보자 친화적인 반복문입니다.

ABAP
1
2
3
4
5 
REPORT zdo_basic.

DO 5 TIMES.
  WRITE: / sy-index, '번째 실행'.
ENDDO.

sy-index는 현재 반복이 몇 번째인지 알려주는 시스템 필드입니다. 첫 번째 반복에서는 1, 두 번째 반복에서는 2처럼 값이 바뀝니다. 시스템 필드는 Lesson 6에서 더 자세히 다룹니다.

DO는 “딱 몇 번 반복할지 알고 있을 때” 쓰기 좋습니다.

3. WHILE: 조건이 참인 동안 반복하기 ⏳

WHILE은 조건이 참인 동안 반복합니다. 횟수보다 조건이 더 중요할 때 사용합니다.

REPORT zwhile_basic.

DATA gv_count TYPE i VALUE 0.

WHILE gv_count < 3.
  gv_count = gv_count + 1.
  WRITE: / gv_count, '회차'.
ENDWHILE.

위 예제는 gv_count가 3보다 작은 동안 반복합니다. 반복 안에서 gv_count를 1씩 올리기 때문에 결국 조건이 거짓이 되고 반복이 끝납니다.

⚠️

WHILE은 무한 반복을 특히 조심하세요

조건이 언젠가 거짓이 되도록 반복 안에서 값을 바꿔야 합니다. gv_count = gv_count + 1. 같은 변화가 없다면 프로그램이 계속 돌 수 있습니다.

4. EXIT과 CONTINUE: 멈추거나 건너뛰기 🚪

반복 중간에 특별한 상황이 생기면 흐름을 조절해야 합니다. 이때 EXIT과 CONTINUE를 사용합니다.

  • EXIT: 반복문을 완전히 빠져나갑니다.
  • CONTINUE: 현재 회차의 남은 코드를 건너뛰고 다음 반복으로 넘어갑니다.

REPORT zloop_control.

DO 5 TIMES.
  IF sy-index = 2.
    CONTINUE.
  ENDIF.

  IF sy-index = 4.
    EXIT.
  ENDIF.

  WRITE: / sy-index.
ENDDO.

위 예제는 2번째 회차에서는 출력을 건너뛰고, 4번째 회차에서는 반복을 끝냅니다. 그래서 Output List에는 1과 3만 보입니다.

5. 정상 흐름과 오류 흐름으로 확인하기 🔎

  • ✅ 정상 흐름: DO 5 TIMES는 5번 실행되고 ENDDO.에서 끝납니다.
  • ✅ 조건 종료: WHILE 안에서 카운터가 증가해 조건이 거짓이 되면 반복이 끝납니다.
  • ❌ ENDDO / ENDWHILE 누락: 반복문을 닫지 않으면 문법 오류가 납니다.
  • ❌ 무한 반복: WHILE 조건이 계속 참이면 프로그램이 끝나지 않을 수 있습니다.
  • ❌ EXIT 남용: 여기저기서 반복을 빠져나가면 흐름을 읽기 어려워집니다.

미니 실습으로 DO 10 TIMES를 작성하고, 짝수 회차만 건너뛰거나 특정 회차에서 멈추도록 바꿔보세요. 조건문과 반복문이 함께 움직이는 감각이 생깁니다.

6. 실무에서 조심해야 할 점 🚨

⚠️

반복문은 성능 문제의 시작점이 될 수 있습니다

작은 예제에서는 5번 반복이라 가볍지만, 실무에서는 수천 건, 수십만 건 데이터를 반복할 수 있습니다. 반복 안에서 무거운 작업을 계속 호출하면 프로그램이 느려집니다. 지금은 문법만 배우지만, 나중에는 반복 횟수와 반복 안의 작업 비용을 함께 봐야 합니다.

데이터베이스 조회와 Internal Table 반복은 이후 Lesson에서 깊게 다룹니다. 이번 단계에서는 DO, WHILE, EXIT, CONTINUE의 기본 움직임을 정확히 잡는 데 집중합니다.

오늘의 핵심만 딱 잡기
