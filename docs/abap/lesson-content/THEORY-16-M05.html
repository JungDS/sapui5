학습 목표

문자열을 깔끔하게 조립하는 String Template(|...|)을 배웁니다. 변수 끼워 넣기, 자리수·날짜 서식, 그리고 자주 쓰는 문자열 내장 함수를 익힙니다.

1. 지난 시간 연결: 문자열 이어 붙이기가 지저분하다 🧵

예전에는 문자열을 합칠 때 CONCATENATE a b c INTO result SEPARATED BY space.처럼 길게 썼습니다. 변수와 글자를 섞으면 더 복잡했죠.

최신 ABAP의 String Template은 막대기(|) 사이에 글자와 변수를 자유롭게 섞어 한 번에 만듭니다.

2. 막대기와 중괄호 ✍️

ABAP
1
2
3 
DATA(lv_name) = '홍길동'.
DATA(lv_msg) = |안녕하세요, { lv_name }님! 환영합니다.|.
"→ "안녕하세요, 홍길동님! 환영합니다."
  • | ... |: 문자열 템플릿의 시작과 끝.
  • { 변수 }: 중괄호 안의 변수 값이 그 자리에 들어갑니다.
💡

서식도 끼워서

중괄호 안에서 서식을 줄 수 있어요. 날짜는 { lv_date DATE = USER }(사용자 형식), 숫자는 { lv_amount NUMBER = USER }처럼요. 소수점·앞자리 0 채우기(WIDTH, PAD, ALIGN) 같은 옵션도 있습니다.

3. 자주 쓰는 문자열 함수 🔧

최신 ABAP은 문자열을 다루는 내장 함수를 많이 제공합니다.

  • strlen( txt ): 길이
  • to_upper( txt ) / to_lower( txt ): 대문자/소문자
  • condense( txt ): 불필요한 공백 정리
  • replace( val = .. sub = .. with = .. ): 치환
  • substring( val = .. off = .. len = .. ): 부분 문자열

4. 정상 흐름과 오류 흐름 🔍

  • ✅ 정상: 템플릿으로 글자+변수+서식을 한 번에 조립해 가독성이 좋아집니다.
  • ❌ 오류 1: 숫자/날짜를 서식 없이 그대로 끼우면, 내부 형식(예: 날짜 20260609)이 그대로 나와 보기 나쁩니다. 서식 옵션을 쓰세요.
  • ❌ 오류 2: 아주 큰 반복 루프에서 문자열을 계속 이어 붙이면 성능이 떨어질 수 있습니다. 대량은 다른 방법을 고려.

5. 실무에서 조심할 점 🚨

⚠️

숫자·날짜·금액은 "사용자 형식"으로

화면이나 메시지에 날짜·숫자를 보여줄 때는 내부 형식이 아니라 사용자 설정 형식으로 변환해야 합니다. String Template의 DATE = USER, NUMBER = USER 같은 옵션을 쓰면 사용자의 국가/언어 설정에 맞게 표시됩니다. 이걸 빠뜨리면 "20260609"나 "1000.00" 같은 날것이 그대로 노출됩니다.

6. 한눈에 정리 🏁

📝

오늘의 핵심만 딱 잡기

  • String Template |글자 { 변수 } 글자|로 문자열을 깔끔히 조립합니다.
  • 중괄호 안에서 DATE/NUMBER = USER 등 서식을 줄 수 있습니다.
  • strlen·to_upper·condense·replace·substring 등 내장 함수를 활용합니다.
  • 날짜·숫자는 사용자 형식으로 변환해 보여줍니다.
