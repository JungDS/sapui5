학습 목표

표의 칸(셀) 하나하나에 색을 입히는 Cell Color를 배웁니다. THEORY-07에서 배운 Deep Structure를 이용해, 출력 테이블 안에 색상 정보 테이블(LVC_T_SCOL)을 품는 구조를 익힙니다.

1. 지난 시간 연결: 행/컬럼 말고 "칸" 단위 색 🎨

THEORY-15에서 행 색상(전체 줄)과 컬럼 색상(전체 열)을 배웠습니다. 그런데 "이 줄의 이 칸만 빨갛게"처럼 특정 셀 하나를 강조하고 싶을 때가 있습니다. 예: 재고가 부족한 자재의 '수량' 칸만 빨강.

이 정밀 제어가 Cell Color이고, 여기서 Deep Structure가 필요해집니다.

2. 출력 구조 안에 색상 테이블을 품는다 ✍️

셀마다 다른 색을 주려면, 각 행이 "어느 칸을 무슨 색으로"라는 정보를 들고 있어야 합니다. 그래서 출력 구조 안에 LVC_T_SCOL(색상 정보 Internal Table)을 컬럼으로 넣습니다 — 이것이 Deep Structure입니다. 

TYPES: BEGIN OF ty_row,
         carrid TYPE s_carr_id,
         price  TYPE s_price,
         cellcolors TYPE lvc_t_scol,   "★ 셀 색상 정보(테이블 in 구조)
       END OF ty_row.
💡

비유: 줄마다 붙은 색칠 메모지

각 행(줄)이 "내 칸들 중 PRICE는 빨강"이라고 적힌 메모지(cellcolors)를 하나씩 들고 다니는 거예요. ALV는 그 메모지를 읽어 칸을 칠합니다.

3. 색 채우고 Layout에 연결 🔗

" 조건에 맞는 행의 특정 셀에 색 지정
LOOP AT gt_out ASSIGNING FIELD-SYMBOL(<fs>).
  IF <fs>-price > 1000.
    APPEND VALUE lvc_s_scol(
      fname = 'PRICE'                 "이 칸을
      color = VALUE #( col = 6 ) )    "빨강(6) 계열로
      TO <fs>-cellcolors.
  ENDIF.
ENDLOOP.

" Layout에 "색상 정보 필드 이름" 알려주기
gs_layout-ctab_fname = 'CELLCOLORS'.
  • fname: 색을 줄 컬럼 이름.
  • color-col: 색 번호(THEORY-15의 Cxyz 색 코드 체계).
  • ctab_fname: Layout에 "셀 색상 정보가 이 필드에 있다"고 알려줌.

4. 정상 흐름과 오류 흐름 🔍

  • ✅ 정상: 색상 필드 + ctab_fname 연결 → 조건에 맞는 셀만 정확히 칠해짐.
  • ❌ 오류 1: ctab_fname을 안 알려줌 → 색을 채워도 표시 안 됨(M05의 stylefname과 헷갈리기 쉬움).
  • ❌ 오류 2: fname을 잘못 적음 → 엉뚱한 칸이 칠해지거나 무시됨.

5. 실무에서 조심할 점 🚨

⚠️

Deep Structure는 메모리·복사 비용이 있다

모든 행마다 색상 테이블을 품으면(THEORY-07에서 배운 Deep Structure), 데이터가 많을 때 메모리와 복사 비용이 늘어납니다. 정말 셀 단위 강조가 필요한 경우에만 쓰고, "전체 줄이면 충분"하면 행 색상(가벼움)을 쓰세요. 강조는 꼭 필요한 곳에 절제해서.

6. 한눈에 정리 🏁

📝

오늘의 핵심만 딱 잡기

  • Cell Color는 칸 하나하나를 칠하는 정밀 색상 제어입니다.
  • 출력 구조 안에 LVC_T_SCOL을 품는 Deep Structure로 구현합니다.
  • 각 셀에 fname+color를 채우고 Layout의 ctab_fname으로 연결합니다.
  • 메모리 비용이 있으니 셀 단위가 꼭 필요할 때만 사용합니다.
