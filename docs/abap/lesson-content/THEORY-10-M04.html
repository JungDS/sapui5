학습 목표

지난 Lesson에서 SELECT-OPTIONS를 Open SQL 조건에 연결했습니다. 이번에는 Multiple Selection 화면에서 여러 조건을 넣고, Include와 Exclude가 Range Table에서 어떻게 표현되는지 봅니다.

1. Multiple Selection은 조건 편집 창이다 🧭

SELECT-OPTIONS 입력 필드 오른쪽에는 여러 값을 넣을 수 있는 Multiple Selection 버튼이 있습니다. 사용자는 이 화면에서 단일값 여러 개, 범위, 제외값을 입력할 수 있습니다.

겉으로는 팝업 화면이지만, 내부적으로는 Selection Table의 여러 행을 편집하는 것입니다. 즉 사용자가 여러 줄짜리 Range Table을 만들고 있는 셈입니다.

Multiple Selection은 Range Table 조건표를 사용자 친화적으로 편집하는 화면입니다.

2. Include는 포함 조건이다 ✅

Include는 Range Table의 SIGN = 'I'에 해당합니다. “이 값이나 범위를 조회 대상에 포함해줘”라는 의미입니다.

Include 조건 예시

SIGN OPTION LOW HIGH 의미
I EQ KR KR 포함
I BT A C A부터 C까지 포함

3. Exclude는 빼기 조건이다 🚫

Exclude는 Range Table의 SIGN = 'E'에 해당합니다. “이 값이나 범위는 조회 대상에서 빼줘”라는 의미입니다.

Exclude 조건 예시

SIGN OPTION LOW HIGH 의미
E EQ KP KP 제외

보통은 포함 조건으로 큰 범위를 만든 뒤, 제외 조건으로 특정 값을 빼는 흐름이 읽기 쉽습니다. 제외 조건만 단독으로 쓸 때는 실제 선택 범위를 더 신중히 확인해야 합니다.

4. Include와 Exclude 복합 매칭 시각화 🗺️

사용자가 Multiple Selection 팝업창을 통해 복잡한 조건을 입력했을 때, 데이터베이스가 최종적으로 데이터를 걸러내는 과정을 정훈영 사원의 시나리오로 시각화해 보겠습니다.

사원 범위 (s_empid) Include / Exclude 혼합 매칭

SIGNOPTIONLOWHIGH의미

EEQE002E002는 제외

최종 조회 대상정훈영(E001), 아이유(E003) 2건만 조회됩니다.

ABAP Open SQL은 Include 조건으로 대상을 먼저 모은 뒤, Exclude 조건에 해당하는 행을 제외하는 순서로 조건식을 평가합니다.

5. 정상 흐름과 오류 흐름으로 확인하기 🔎

  • ✅ Include & Exclude 정상 조합: 범위(Include)를 크게 걸어 두고, 그 중 특정 예외 값(Exclude)을 빼는 구조는 안전하고 실무에서 자주 사용됩니다.
  • ✅ 동일 타입 입력: low와 high, 그리고 대상 필드가 동일한 데이터 타입일 때 정상 작동합니다.
  • ❌ 동일 값의 충돌: 같은 값(예: E001)에 대해 Include와 Exclude를 동시에 지정하는 모순된 조건은 논리 버그를 유발합니다.
  • ❌ Exclude 단독 사용 오류: 아무 조건 없이 SIGN = 'E'만 단독으로 주면, 해당 항목 외에 **나머지 전체 데이터**가 모두 딸려 나오므로 엄청난 성능 문제가 생길 수 있습니다.

6. 실무에서 조심해야 할 점 🚨

⚠️

다중 제외 조건은 전체 범위가 있을 때만 유효합니다

실무에서 "특정 국가나 특정 자재만 빼고 조회해 주세요"라는 요청에 따라 제외 조건만 덜렁 SQL에 전달하면 안 됩니다. 반드시 전체 대상을 좁힐 수 있는 일자, 부서 등의 포함 조건(Include)과 함께 제외 조건을 엮어 성능 장애를 방지해야 합니다.

7. 미니 실습: 다중 입력 결과 디버깅하기 🧪

✍️

실습 과제

  1. 예제 코드 zselect_options_multiple을 작성하고 실행합니다.
  2. Multiple Selection 창을 열어 단일값에 KR, 범위에 A~C를 추가(Include)하고 실행 결과를 봅니다.
  3. 제외 단일 값 탭에 KP를 추가(Exclude)한 뒤 실행하여 SIGN = 'E'가 한 줄 더 출력되는 것을 확인합니다.
  4. 동일한 값 KR을 포함 탭과 제외 탭에 동시에 입력해 보고 내부 Range Table 줄 상태를 출력해 봅니다.

완료 조건: 사용자가 다중 조건 창에 입력한 내역이 내부 Range Table 행 구조로 어떻게 매핑되어 출력되는지 검증하면 성공입니다.

9. 확인 퀴즈와 정답/해설 ✅

  1. 사용자가 Multiple Selection 팝업창에서 '제외 단일 값'에 특정 값을 입력하면, 내부 Range Table의 SIGN과 OPTION은 각각 어떻게 저장되나요?
  2. Include(I) 조건과 Exclude(E) 조건이 Range Table에 섞여 있을 때, SQL은 어떤 순서로 필터링을 하나요?
  3. 제외(Exclude) 조건만 하나 등록하고 조회했을 때 발생할 수 있는 가장 큰 리스크는 무엇인가요?
정답/해설 보기
  1. SIGN = 'E' (Exclude), OPTION = 'EQ' (Equal)로 저장됩니다.
  2. 먼저 Include(I) 조건으로 조회 대상을 만족하는 행들을 수집한 뒤, 그중 Exclude(E) 조건에 해당되는 행들을 깎아내는 방식으로 동작합니다.
  3. 제외할 하나의 값 외에 데이터베이스 테이블의 다른 전체 데이터가 조회 대상이 되므로 무제한 조회가 발생하여 대용량 테이블에서 심각한 성능 저하가 발생할 수 있습니다.

10. 한눈에 정리 🏁

📝

Multiple Selection 핵심 정리

  • Multiple Selection 창은 다중 행 Range Table을 만드는 화면 수준의 편집 도구입니다.
  • Include (I)는 쿼리 대상에 포함시킬 값이나 범위를 정의합니다.
  • Exclude (E)는 쿼리 대상에서 누락시킬 예외 값이나 범위를 정의합니다.
  • 제외 조건 단독 사용은 전체 대용량 데이터 로드를 유발하므로 실무에서 극히 조심해야 합니다.

다음 Lesson EQ / BT / CP 옵션 이해에서는 Range Table의 핵심인 OPTION 필드의 주요 값(EQ, BT, CP) 비교와 패턴 검색에 대해 배웁니다.
