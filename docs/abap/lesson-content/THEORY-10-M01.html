학습 목표

Chapter 9에서는 한 값으로 WHERE 조건을 만들었습니다. 이번 Chapter에서는 여러 값과 범위를 표현하는 Range Table을 배웁니다. Range Table 한 줄의 네 칸인 SIGN, OPTION, LOW, HIGH의 역할을 이해합니다.

1. 한 칸 입력만으로는 부족할 때가 있다 🧭

PARAMETERS는 한 값을 입력받기에 좋습니다. 예를 들어 국가 코드 하나, 회사 코드 하나, 날짜 하나처럼 딱 한 칸이면 충분한 경우가 있습니다.

하지만 실무 사용자는 “KR 또는 US”, “A부터 C까지”, “K로 시작하는 값”, “이 값은 제외”처럼 여러 조건을 넣고 싶어 합니다. 이때 ABAP은 Range Table 구조를 사용해 조건 묶음을 표현합니다.

Range Table은 여러 선택 조건을 행 단위로 담는 조건표입니다.

2. Range Table 한 줄은 네 칸으로 읽는다 🧩

Range Table의 각 행은 보통 다음 네 필드를 가집니다.

  • SIGN: 포함할지 제외할지 정합니다. 대표 값은 I(Include), E(Exclude)입니다.
  • OPTION: 비교 방식을 정합니다. 대표 값은 EQ, BT, CP입니다.
  • LOW: 비교 기준의 시작 값 또는 단일 값입니다.
  • HIGH: 범위 비교에서 끝 값을 담습니다. BT에서 주로 사용합니다.

한 줄을 말로 읽으면 “포함/제외 + 어떤 비교 + 시작값 + 끝값”입니다. 처음에는 이 네 칸만 눈에 익혀도 Range Table이 훨씬 덜 무섭습니다.

3. 예시로 말해보기 📋

SIGN OPTION LOW HIGH 말로 읽기
I EQ KR KR을 포함
I BT A C A부터 C까지 포함
E EQ KP KP는 제외

Range Table은 여러 줄을 함께 해석합니다. 그래서 한 줄만 보는 것이 아니라, 조건표 전체가 어떤 선택 범위를 만드는지 보는 습관이 필요합니다.

4. 최소 코드로 Range Table 만들기 ✍️

ABAP
1
2
3
4
5 
DATA r_land1 TYPE RANGE OF t005t-land1.

APPEND VALUE #( sign = 'I' option = 'EQ' low = 'KR' ) TO r_land1.
APPEND VALUE #( sign = 'I' option = 'EQ' low = 'US' ) TO r_land1.
APPEND VALUE #( sign = 'E' option = 'EQ' low = 'KP' ) TO r_land1.

위 코드는 국가 코드용 Range Table을 직접 만든 예시입니다. KR과 US는 포함하고, KP는 제외하는 조건을 표현합니다.

5. 정상 흐름과 오류 흐름으로 확인하기 🔎

  • ✅ 정상 흐름: SIGN, OPTION, LOW, HIGH가 맞게 채워지면 Range Table 조건으로 사용할 수 있습니다.
  • ❌ SIGN 오타: I, E가 아닌 값을 넣으면 조건 해석이 실패할 수 있습니다.
  • ❌ OPTION 오타: EQ, BT, CP 같은 유효 옵션을 정확히 써야 합니다.
  • ❌ BT에 HIGH 누락: 범위 조건인데 끝값이 없으면 의미가 불완전합니다.
  • ❌ Exclude 착각: 제외 조건은 전체 조건표와 함께 해석해야 합니다.

미니 실습으로 BT 조건을 하나 추가하고 LOW/HIGH를 바꿔보세요. “무엇부터 무엇까지”를 말로 설명할 수 있으면 성공입니다.

6. 실무에서 조심해야 할 점 🚨

⚠️

Range Table은 작은 조건 언어입니다

Range Table은 단순 목록이 아니라 Include, Exclude, 단일값, 범위, 패턴을 함께 표현하는 조건 언어에 가깝습니다. 조건이 복잡해질수록 실제로 어떤 데이터가 선택되는지 테스트해야 합니다.

고객사 화면에서는 Range Table을 직접 만들기보다 SELECT-OPTIONS 화면에서 사용자가 입력한 결과로 만나는 경우가 많습니다. 다음 Lesson에서 그 연결을 봅니다.

7. 한눈에 정리 🏁

📝

Range Table 구조 핵심

  • Range Table은 여러 선택 조건을 담는 조건표입니다.
  • SIGN은 포함/제외, OPTION은 비교 방식을 뜻합니다.
  • LOW는 시작값 또는 단일값, HIGH는 범위 끝값입니다.
  • I/E와 EQ/BT/CP 조합을 말로 읽을 수 있어야 합니다.
  • 복잡한 조건표는 반드시 실제 선택 결과를 확인해야 합니다.
