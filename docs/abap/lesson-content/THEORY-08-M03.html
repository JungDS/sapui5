학습 목표

지난 Lesson에서 FACTORY와 DISPLAY로 SALV 화면을 띄웠습니다. 이번에는 Functions Basic을 켜서 기본 기능 버튼을 표시하고, DISPLAY 실행 전 설정 순서를 익힙니다.

1. 표 화면에는 기본 도구가 필요하다 🧭

사용자가 표를 보면 자연스럽게 몇 가지 기능을 기대합니다. 정렬하거나, 필터링하거나, 합계를 보거나, 엑셀로 내려받고 싶어 할 수 있습니다.

SALV는 이런 기본 기능을 제공할 수 있지만, 예제 코드에서는 기능 버튼을 명시적으로 켜는 흐름을 자주 봅니다. 이번 Lesson에서는 가장 기본적인 get_functions( )와 set_all( ) 감각만 잡습니다.

SALV 설정은 DISPLAY 전에 끝내야 합니다. 화면을 보여준 뒤가 아니라, 보여주기 전에 준비합니다.

2. Functions 객체 가져오기 🧰

SALV의 기본 기능 버튼을 제어하려면 Functions 객체를 가져옵니다.

ABAP
1
2
3
4 
DATA lo_functions TYPE REF TO cl_salv_functions_list.

lo_functions = lo_alv->get_functions( ).
lo_functions->set_all( abap_true ).
  • get_functions( ): SALV의 기능 버튼 설정 객체를 가져옵니다.
  • set_all( abap_true ): 기본 기능을 전체 활성화합니다.
  • abap_true: 참 값을 표현하는 ABAP 상수입니다.

지금은 각 버튼의 세부 기능을 외울 필요는 없습니다. “SALV 객체에서 기능 설정 객체를 꺼내고, 기본 기능을 켠다” 정도로 이해하세요.

3. 설정 순서: FACTORY → Functions → DISPLAY 🔁

ABAP
1
2
3
4

8 
cl_salv_table=>factory(
  IMPORTING r_salv_table = lo_alv
  CHANGING  t_table      = lt_students ).

lo_functions = lo_alv->get_functions( ).
lo_functions->set_all( abap_true ).

lo_alv->display( ).

핵심은 순서입니다. 먼저 FACTORY로 lo_alv가 만들어져야 Functions를 꺼낼 수 있습니다. 그리고 DISPLAY 전에 기능 설정을 끝내야 화면에 반영됩니다.

💡

요리 순서처럼 생각하기

재료 준비(Internal Table), 접시 준비(FACTORY), 토핑 올리기(Functions 설정), 손님에게 내기(DISPLAY) 순서입니다.

DATA: lo_alv       TYPE REF TO cl_salv_table,
      lo_functions TYPE REF TO cl_salv_functions_list,
      lx_msg       TYPE REF TO cx_salv_msg.

TRY.
    cl_salv_table=>factory(
      IMPORTING r_salv_table = lo_alv
      CHANGING  t_table      = lt_students ).

    lo_functions = lo_alv->get_functions( ).
    lo_functions->set_all( abap_true ).

    lo_alv->display( ).

  CATCH cx_salv_msg INTO lx_msg.
    MESSAGE lx_msg->get_text( ) TYPE 'E'.
ENDTRY.

이 조각은 Lesson 2 전체 예제의 SALV 부분에 붙여 사용할 수 있습니다. 실제 화면에서는 표 위쪽에 기본 기능 버튼들이 표시됩니다.

5. 정상 흐름과 오류 흐름으로 확인하기 🔎

  • ✅ 정상 흐름: FACTORY 성공 후 Functions를 가져오고, set_all로 기능을 켠 뒤 DISPLAY합니다.
  • ❌ FACTORY 전 호출: lo_alv가 아직 준비되지 않았는데 get_functions를 호출하면 문제가 됩니다.
  • ❌ DISPLAY 후 설정: 화면을 이미 표시한 뒤 기능을 설정하면 사용자가 기대한 화면과 다를 수 있습니다.
  • ❌ 심화 기능 착각: 기본 버튼을 켰다고 모든 레이아웃/Variant 설계가 끝난 것은 아닙니다.

미니 실습으로 set_all( abap_true ) 줄을 빼고 실행한 화면과 넣고 실행한 화면을 비교해보세요. 화면 상단 기능 차이를 관찰하는 것이 목표입니다.

6. 실무에서 조심해야 할 점 🚨

⚠️

기본 기능 표시와 업무 기능 설계는 다릅니다

SALV 기본 기능을 켜는 것은 사용자 편의의 시작일 뿐입니다. 특정 버튼을 숨기거나, Layout Variant를 관리하거나, 이벤트를 붙이는 일은 후속 심화 범위입니다.

이번 단계에서는 “표를 보여주고 기본 기능을 켠다”까지만 정확히 익히면 됩니다. 복잡한 ALV 제어는 나중에 OO ABAP과 ALV 심화에서 다룹니다.

기본 Function 핵심

  • Functions Basic은 SALV 표의 기본 기능 버튼을 다루는 첫 단계입니다.
  • get_functions( )로 기능 설정 객체를 가져옵니다.
  • set_all( abap_true )로 기본 기능을 활성화할 수 있습니다.
  • 순서는 FACTORY → Functions 설정 → DISPLAY입니다.
  • Layout/Variant/Event 심화는 이번 Chapter 범위를 넘깁니다.
