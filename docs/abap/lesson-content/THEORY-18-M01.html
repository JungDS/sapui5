학습 목표

객체지향 ABAP의 출발점, Global Class를 만드는 법과 클래스의 기본 구조를 배웁니다. 절차형(FORM/Function)과 무엇이 다른지, 왜 클래스로 가는지 큰 그림을 잡습니다.

1. 지난 시간 연결: 함수 묶음에서 "객체"로 🧩

THEORY-05에서 FORM과 Function Module로 코드를 모듈화했습니다. 잘 동작하지만, 데이터와 그 데이터를 다루는 로직이 따로 떨어져 있었습니다.

객체지향(OO) ABAP은 "데이터(속성)와 로직(메서드)을 하나의 묶음(클래스)으로" 합칩니다. 신규 SAP 개발(특히 RAP·ABAP Cloud)은 거의 전부 클래스 기반입니다.

2. 클래스와 객체 🏭

  • 클래스(Class): "설계도". 어떤 데이터와 기능을 가질지 정의합니다.
  • 객체(Object): 설계도로 찍어낸 "실물". 클래스를 바탕으로 메모리에 만든 실제 인스턴스입니다.
💡

비유: 붕어빵 틀과 붕어빵

클래스는 붕어빵 틀(설계도), 객체는 그 틀로 구운 붕어빵(실물)이에요. 틀 하나로 붕어빵을 여러 개 찍어내듯, 클래스 하나로 객체를 여러 개 만듭니다.

3. Global Class의 구조 ✍️

Global Class는 시스템 어디서나 재사용할 수 있는 클래스로, 보통 ZCL_로 시작합니다. ADT나 SE24에서 만듭니다.

CLASS zcl_flight DEFINITION   "선언부: 무엇을 가질지

  PUBLIC.
  PUBLIC SECTION.
    METHODS get_price RETURNING VALUE(rv_price) TYPE s_price.
ENDCLASS.

CLASS zcl_flight IMPLEMENTATION.   "구현부: 어떻게 동작할지

  METHOD get_price.
    rv_price = 900.
  ENDMETHOD.
ENDCLASS.
  • DEFINITION(선언부): 속성·메서드의 "목록과 모양"을 적습니다.
  • IMPLEMENTATION(구현부): 메서드가 "실제로 하는 일"을 적습니다.

4. 객체 만들어 쓰기 🛠️

ABAP
1
2 
DATA(lo_flight) = NEW zcl_flight( ).   "객체 생성 (NEW)

DATA(lv_price)  = lo_flight->get_price( ).  "메서드 호출 (->)
  • NEW: 설계도(클래스)로 실물(객체)을 만듭니다.
  • ->: 객체의 메서드·속성에 접근합니다.

5. 실무에서 조심할 점 🚨

⚠️

처음엔 어려워 보여도 "묶음"이 핵심

클래스 문법(DEFINITION/IMPLEMENTATION, SECTION 등)이 처음엔 복잡해 보입니다. 하지만 본질은 단순합니다. "관련된 데이터와 기능을 한 묶음으로 모은다"는 것. 그래야 재사용·테스트·유지보수가 쉬워집니다. 문법을 외우기보다, 이 "묶음" 개념을 먼저 잡으면 나머지가 자연스럽게 따라옵니다.

6. 한눈에 정리 🏁

📝

오늘의 핵심만 딱 잡기

  • OO ABAP은 데이터와 로직을 클래스라는 묶음으로 합칩니다.
  • 클래스=설계도, 객체=실물(붕어빵 틀과 붕어빵).
  • 클래스는 DEFINITION(선언)+IMPLEMENTATION(구현)으로 구성됩니다.
  • NEW로 객체를 만들고 ->로 메서드를 호출합니다.

클래스의 뼈대를 봤으니, 안을 채워봅니다. 다음 Lesson Attribute / Method / Visibility에서 클래스의 속성·메서드와 공개 범위를 배웁니다.
