학습 목표

화면 위쪽의 메뉴·툴바·기능키를 정의하는 PF-STATUS와, 창 제목을 정하는 TITLEBAR를 배웁니다. 버튼이 동작하려면 PF-STATUS의 Function Code와 PAI가 어떻게 연결되는지 익힙니다.

1. 지난 시간 연결: 버튼은 어디서 오는가? 🔘

PAI에서 ok_code = 'SAVE'를 처리했는데, 정작 그 "저장" 버튼은 어디서 만들까요? 화면 본문에 직접 그릴 수도 있지만, 보통 위쪽 툴바·메뉴에 둡니다. 이 메뉴·툴바·기능키 묶음을 정의하는 것이 PF-STATUS(GUI Status)입니다.

2. PF-STATUS = 메뉴·툴바·기능키 묶음 ✍️

PF-STATUS는 트랜잭션 SE41(Menu Painter) 또는 SE80에서 만듭니다. 여기에 메뉴 항목과 툴바 버튼을 배치하고, 각각에 Function Code를 줍니다. 그리고 PBO에서 적용합니다.

ABAP
1
2
3
4 
MODULE status_0100 OUTPUT.
  SET PF-STATUS 'STAT_0100'.   "이 화면의 메뉴/툴바 적용

  SET TITLEBAR  'TITLE_0100'.  "창 제목 적용

ENDMODULE.
🔗

연결 고리: Function Code

PF-STATUS의 버튼에 준 Function Code(SAVE, BACK)가, 사용자가 그 버튼을 누를 때 OK_CODE로 전달되어 PAI의 CASE에서 처리됩니다. PF-STATUS(버튼 정의) ↔ PAI(버튼 처리)가 Function Code로 이어지는 거예요.

3. TITLEBAR로 제목 달기 🏷️

TITLEBAR는 창 위쪽에 뜨는 제목 텍스트입니다. SET TITLEBAR 'TITLE_0100'처럼 적용하며, 제목에 변수를 끼워 넣을 수도 있습니다.

ABAP
1
2 
SET TITLEBAR 'TITLE_0100' WITH gv_name.
"→ 제목이 "홍길동님 상세 정보"처럼 동적으로 표시

4. 정상 흐름과 오류 흐름 🔍

  • ✅ 정상: PBO에서 PF-STATUS·TITLEBAR 적용 → 메뉴·툴바·제목이 제대로 표시되고 버튼이 동작.
  • ❌ 오류 1: SET PF-STATUS 누락 → 툴바가 비어 BACK·SAVE 버튼이 아예 안 보임.
  • ❌ 오류 2: 표준 기능키(예: F3=뒤로)에 Function Code를 안 주면, 사용자가 뒤로 가기를 못 함.

5. 실무에서 조심할 점 🚨

⚠️

표준 기능키 관례를 지키세요

SAP에는 사용자가 익숙한 기능키 관례가 있습니다. F3=뒤로(BACK), F12=취소(CANCEL), Shift+F3=종료(EXIT) 등입니다. 이를 무시하고 제멋대로 배치하면 사용자가 헷갈립니다. 표준 Function Code와 위치를 따르는 것이 좋은 화면의 기본 예의입니다.

6. 한눈에 정리 🏁

📝

오늘의 핵심만 딱 잡기

  • PF-STATUS는 메뉴·툴바·기능키 묶음으로, SE41에서 만들고 PBO에서 SET 합니다.
  • TITLEBAR는 창 제목이며, WITH로 변수를 끼워 동적으로 표시할 수 있습니다.
  • 버튼의 Function Code가 OK_CODE로 전달되어 PAI에서 처리됩니다.
  • F3(뒤로)·F12(취소) 등 표준 기능키 관례를 지킵니다.
