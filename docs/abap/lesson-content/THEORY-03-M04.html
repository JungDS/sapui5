학습 목표

이번 Chapter의 마지막 Lesson에서는 Selection Screen 입력칸을 보기 좋게 묶는 Selection Screen Block을 맛봅니다. SELECTION-SCREEN BEGIN OF BLOCK과 FRAME TITLE로 입력 영역에 테두리와 제목을 붙이는 기본 흐름만 다룹니다.

1. 지난 시간 연결: 입력칸이 많아지면 정리가 필요하다 🗃️

이전 Lesson에서는 PARAMETERS 입력값을 WRITE로 출력했습니다. 입력칸이 한두 개일 때는 화면이 단순합니다. 하지만 실제 Report 프로그램은 회사 코드, 기간, 상태, 담당자처럼 여러 입력값을 받을 수 있습니다.

입력칸이 늘어나면 사용자는 “이 칸들이 어떤 그룹인지” 알고 싶어집니다. Selection Screen Block은 관련 있는 입력칸들을 묶어 테두리와 제목을 붙이는 기본 도구입니다.

Block은 Selection Screen의 작은 박스 정리함입니다. 관련 입력값을 한눈에 묶어 보여줍니다.

2. BEGIN OF BLOCK과 END OF BLOCK 기본 모양 🧱

SELECTION-SCREEN BEGIN OF BLOCK은 입력 그룹의 시작을 알립니다. 끝에는 SELECTION-SCREEN END OF BLOCK을 써서 닫습니다.

REPORT zparam_block.

SELECTION-SCREEN BEGIN OF BLOCK b1 WITH FRAME TITLE text-001.
  PARAMETERS p_carr TYPE c LENGTH 3 DEFAULT 'KE'.
  PARAMETERS p_days TYPE i DEFAULT 7.
SELECTION-SCREEN END OF BLOCK b1.

WRITE: / '항공사:', p_carr,
       / '조회 일수:', p_days.

b1은 Block 이름입니다. 같은 프로그램 안에서 구분할 수 있는 짧은 이름을 붙입니다. WITH FRAME은 테두리를 보여주겠다는 뜻이고, TITLE text-001은 제목 텍스트를 연결합니다.

3. FRAME TITLE은 박스의 제목표 🏷️

FRAME TITLE은 Block 테두리에 표시할 제목입니다. 사용자는 제목을 보고 “아, 이 영역은 조회 조건이구나”처럼 빠르게 이해할 수 있습니다.

💡

text-001은 어디서 오나요?

text-001은 ABAP 프로그램의 텍스트 심볼(Text Symbol)을 의미합니다. 예를 들어 text-001에 “기본 조회 조건”이라는 문구를 등록해두면, Block 제목으로 그 문구가 표시됩니다.

초심자 단계에서는 텍스트 심볼 관리 화면까지 깊게 들어가지 않아도 됩니다. “Block 제목을 직접 코드 문자열로 박아두기보다, 텍스트 심볼을 통해 관리할 수 있다”는 감각만 잡으면 충분합니다.

4. 최소 실습: 기본 조건 박스 만들기 🧪

아래 예제는 조회 조건을 한 박스로 묶습니다. 아직 데이터베이스 조회는 하지 않고, 입력값을 출력해 확인하는 수준입니다.

ABAP

REPORT zselection_block.

SELECTION-SCREEN BEGIN OF BLOCK b_cond WITH FRAME TITLE text-001.
  PARAMETERS p_carr TYPE c LENGTH 3 DEFAULT 'KE' OBLIGATORY.
  PARAMETERS p_date TYPE d DEFAULT sy-datum.
SELECTION-SCREEN END OF BLOCK b_cond.

WRITE: / '항공사:', p_carr,
       / '기준일:', p_date.
  • b_cond는 조건 영역을 뜻하는 Block 이름입니다.
  • p_carr와 p_date는 같은 박스 안에 표시됩니다.
  • text-001에는 예를 들어 “조회 조건” 같은 제목을 등록할 수 있습니다.

화면에서 입력 필드들이 박스 안에 묶여 보이면 성공입니다. 프로그램이 더 전문적으로 보이는 작은 변화지만, 사용자가 화면을 이해하는 속도는 꽤 달라집니다.

5. 정상 흐름과 오류 흐름으로 확인하기 🔎

  • ✅ 정상 흐름: BEGIN OF BLOCK과 END OF BLOCK 사이의 PARAMETERS가 하나의 프레임 안에 묶여 표시됩니다.
  • ✅ 제목 표시: 텍스트 심볼이 준비되어 있으면 FRAME TITLE에 제목이 보입니다.
  • ❌ END 누락: Block을 시작하고 닫지 않으면 문법 오류가 납니다.
  • ❌ 텍스트 심볼 누락: text-001을 연결했지만 텍스트를 관리하지 않으면 제목이 기대와 다르게 보일 수 있습니다.
  • ❌ 과도한 확장: 이번 Lesson에서는 SELECT-OPTIONS와 AT SELECTION-SCREEN 검증 이벤트를 다루지 않습니다.

6. 실무에서 조심해야 할 점 🚨

⚠️

박스를 많이 만든다고 좋은 화면은 아닙니다

Block은 입력 화면을 정리해주지만, 너무 많은 박스와 제목을 만들면 오히려 화면이 복잡해집니다. 같은 목적의 입력값만 묶고, 제목은 짧고 명확하게 붙이는 것이 좋습니다.

또한 회사별로 Selection Screen 구성 스타일이 다를 수 있습니다. 표준 문법은 같지만, 어떤 입력값을 어떤 그룹으로 묶을지는 업무 화면 설계의 영역입니다. 표준 동작과 고객사 UI 관행을 구분해서 이해하세요.

Chapter 3 마무리 핵심

  • Selection Screen Block은 관련 입력 필드를 하나의 영역으로 묶습니다.
  • SELECTION-SCREEN BEGIN OF BLOCK으로 시작하고 END OF BLOCK으로 닫습니다.
  • WITH FRAME은 테두리를 표시하고, FRAME TITLE은 영역 제목을 붙입니다.
  • text-001 같은 텍스트 심볼을 제목으로 연결할 수 있습니다.
  • 이번 Chapter는 PARAMETERS 맛보기까지이며, SELECT-OPTIONS와 입력 검증 이벤트는 뒤에서 다룹니다.
