학습 목표

화면 안에 표(ALV)·브라우저 같은 복잡한 부품을 끼워 넣는 자리인 Custom Control과, 그 자리에 부품을 담는 Container 개념을 배웁니다. 다음 Chapter의 Grid ALV로 가는 다리를 놓습니다.

1. 지난 시간 연결: 기본 부품만으로는 부족하다 🧱

지금까지 배운 Input/Text/Button은 단순한 입력 폼에는 충분합니다. 하지만 "조회 결과를 표로 보여주기", "차트 그리기", "HTML 문서 띄우기" 같은 복잡한 부품은 이런 기본 요소로는 만들 수 없습니다.

그래서 Dynpro에는 화면 한 구역을 빈 자리로 비워두고, 거기에 강력한 부품(컨트롤)을 끼워 넣는 방식이 있습니다. 그 빈 자리가 Custom Control입니다.

2. Custom Control = 화면 속 빈 자리 🪟

Screen Painter에서 화면에 Custom Control 영역을 그리고 이름(예: CC_ALV)을 줍니다. 이 자리는 비어 있고, 프로그램이 실행될 때 코드로 부품을 심습니다.

💡

비유: 액자 걸이 못

벽에 못(Custom Control)을 박아두면, 거기에 그림(ALV)이든 거울(브라우저)이든 걸 수 있어요. 못 자체는 빈 자리일 뿐이고, 무엇을 걸지는 프로그램이 정합니다.

3. Container가 부품을 담는다 ✍️

Custom Control 자리에 실제로 부품을 담으려면 Container 객체가 필요합니다. 대표적으로 CL_GUI_CUSTOM_CONTAINER를 만들어 화면의 Custom Control과 연결합니다.

DATA: go_container TYPE REF TO cl_gui_custom_container,
      go_alv       TYPE REF TO cl_gui_alv_grid.

" PBO에서 (처음 한 번만)
IF go_container IS INITIAL.
  CREATE OBJECT go_container
    EXPORTING container_name = 'CC_ALV'.   "화면의 Custom Control 이름
  CREATE OBJECT go_alv
    EXPORTING i_parent = go_container.      "그 자리에 ALV를 담음
ENDIF.
  • Container: Custom Control 자리에 대응하는 ABAP 객체(그릇).
  • 부품: 그 그릇(i_parent)에 ALV Grid·HTML Viewer 등을 담습니다.

4. 정상 흐름과 오류 흐름 🔍

  • ✅ 정상: Custom Control(화면) ↔ Container(객체) ↔ 부품(ALV)이 연결되면, 화면 안에 표가 뜹니다.
  • ❌ 오류 1: Container를 PBO마다 새로 생성 → 객체가 중복 생성되어 깨짐. IS INITIAL 체크로 처음 한 번만 만듭니다.
  • ❌ 오류 2: 화면의 Custom Control 이름과 코드의 container_name이 다르면 부품이 안 붙습니다.

5. 실무에서 조심할 점 🚨

⚠️

객체는 한 번만 만들고 재사용하세요

Container와 ALV 같은 GUI 객체는 무겁습니다. PBO가 실행될 때마다 새로 만들면 메모리 누수와 화면 깜빡임이 생깁니다. 반드시 "이미 만들었는지" 확인하고, 처음 한 번만 생성한 뒤 이후에는 데이터만 갱신(refresh)하는 것이 원칙입니다. 이 객체 다루기는 OO ABAP(THEORY-18)을 배우면 더 분명해집니다.

6. 한눈에 정리 🏁

THEORY-14 마무리 핵심

  • Dynpro는 Module Pool 안에서 PBO(준비)↔PAI(반응) 박자로 동작합니다.
  • 기본 요소는 Input/Text/Button, 메뉴·툴바는 PF-STATUS, 제목은 TITLEBAR.
  • 복잡한 부품은 Custom Control(빈 자리) + Container(그릇)로 끼워 넣습니다.
  • GUI 객체는 처음 한 번만 생성하고 재사용합니다.

Container에 담을 가장 대표적인 부품이 바로 표(Grid ALV)입니다. 다음 Chapter Grid ALV 기초에서, 이 Custom Control 위에 본격적인 데이터 표를 띄우는 법을 배웁니다.
