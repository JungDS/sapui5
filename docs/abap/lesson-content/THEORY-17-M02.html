학습 목표

ABAP 변수 앞에 붙이는 골뱅이(@), 즉 Host Variable의 의미를 배웁니다. 변수뿐 아니라 계산식을 넣는 Host Expression까지 익힙니다.

1. 지난 시간 연결: @는 "이건 ABAP이야"라는 표시 🏷️

SELECT 문 안에는 두 세계가 섞입니다. DB 세계(테이블·컬럼)와 ABAP 세계(프로그램 변수)입니다. 둘을 섞어 쓰면 컴파일러가 "이 단어가 컬럼이야, 변수야?" 헷갈릴 수 있습니다.

그래서 Modern SQL은 ABAP 쪽 값 앞에 @를 붙여 "이건 ABAP 변수다"라고 분명히 표시합니다. 이를 Host Variable이라고 합니다.

2. Host Variable 기본 ✍️

ABAP

DATA(lv_carrid) = 'LH'.

SELECT connid, price
  FROM sflight
  WHERE carrid = @lv_carrid        "@lv_carrid = ABAP 변수

  INTO TABLE @DATA(lt).            "@DATA = ABAP 결과 그릇
  • carrid (@ 없음): DB 테이블의 컬럼.
  • @lv_carrid (@ 있음): ABAP 프로그램의 변수.
💡

비유: 두 나라 말이 섞인 문장

한 문장에 한국어와 영어가 섞이면 헷갈리죠. @는 "지금부터 이 단어는 ABAP(우리 쪽) 말이야"라고 밑줄 그어주는 표시예요. 덕분에 오해가 없습니다.

3. Host Expression — 계산식도 넣기 🧮

@ 다음에는 단순 변수뿐 아니라, 괄호로 묶은 계산식(Host Expression)도 넣을 수 있습니다.

ABAP

SELECT carrid, connid
  FROM sflight
  WHERE price >= @( lv_base * 2 )    "ABAP 계산식을 바로 사용

  INTO TABLE @DATA(lt).

@( ... ) 안에서 ABAP 식을 계산한 결과가 조건에 쓰입니다. 미리 변수를 만들 필요가 줄어듭니다.

4. 정상 흐름과 오류 흐름 🔍

  • ✅ 정상: ABAP 값엔 @, DB 컬럼엔 @ 없이 → 컴파일러가 정확히 구분.
  • ❌ 오류 1: ABAP 변수에 @를 빠뜨림 → "그런 컬럼 없다"는 오류(변수를 컬럼으로 오해).
  • ❌ 오류 2: DB 컬럼에 @를 잘못 붙임 → 역시 오류. @는 ABAP 쪽에만.

5. 실무에서 조심할 점 🚨

⚠️

@는 선택이 아니라 필수입니다

Modern SQL(콤마 스타일)에서는 ABAP 변수 앞 @가 의무입니다. "예전엔 안 붙여도 됐는데"라며 빠뜨리면 컴파일이 안 됩니다. 처음엔 번거롭게 느껴져도, @ 덕분에 코드를 읽는 사람이 DB와 ABAP를 한눈에 구분할 수 있어 실수가 줄어듭니다. 익숙해지면 오히려 편합니다.

오늘의 핵심만 딱 잡기

  • Host Variable(@변수)은 "이건 ABAP 값"이라는 표시입니다.
  • DB 컬럼엔 @ 없이, ABAP 값엔 @를 붙입니다.
  • Host Expression @( 식 )으로 계산식도 바로 넣습니다.
  • Modern SQL에서 @는 선택이 아니라 필수입니다.
