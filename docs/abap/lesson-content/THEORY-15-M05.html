학습 목표

표 전체의 외형을 정하는 Layout(LVC_S_LAYO)을 배웁니다. 줄무늬(Zebra), 자동 너비 최적화(CWIDTH_OPT), 행 색상 지정 필드(INFO_FNAME)를 익힙니다.

1. 지난 시간 연결: 컬럼 말고 "표 전체" 꾸미기 🎨

Field Catalog가 컬럼 하나하나를 설명했다면, Layout은 표 전체의 외형을 정합니다. 줄무늬를 넣을지, 너비를 자동으로 맞출지, 행 색은 어떻게 할지 같은 "표 단위" 설정이죠.

Layout은 LVC_S_LAYO라는 구조 하나에 값을 채워 전달합니다.

DATA gs_layout TYPE lvc_s_layo.

gs_layout-zebra      = 'X'.        "줄무늬(짝/홀 행 음영)

gs_layout-cwidth_opt = 'X'.        "컬럼 너비 자동 최적화

gs_layout-info_fname = 'ROWCOLOR'. "행 색상을 담는 필드명

gs_layout-grid_title = '항공편 목록'."표 제목
  • zebra: 한 줄 걸러 음영을 넣어 가독성을 높입니다.
  • cwidth_opt: 데이터 길이에 맞춰 컬럼 너비를 자동 조정합니다.
  • info_fname: 각 행의 색상 코드를 담을 필드 이름(행 색상 기능, M09에서 활용).
💡

비유: 표 전체 테마

Field Catalog가 "각 열의 이름표"라면, Layout은 "표 전체에 적용하는 테마(줄무늬, 너비, 색)"예요. 한 번 정하면 표 전체에 일괄 적용됩니다.

3. cwidth_opt의 편리함과 한계 ⚖️

  • ✅ 장점: 값이 잘리지 않게 너비를 자동으로 맞춰줘 편합니다.
  • ⚠️ 한계: 데이터가 길면 컬럼이 과하게 넓어질 수 있습니다. 중요한 컬럼은 Field Catalog의 outputlen으로 직접 지정하는 편이 안정적일 때도 있습니다.

4. 정상 흐름과 오류 흐름 🔍

  • ✅ 정상: Layout 구조를 채워 표시 메서드에 함께 넘기면 표 전체에 적용됩니다.
  • ❌ 오류 1: info_fname에 적은 필드(ROWCOLOR)가 출력 테이블에 없으면 행 색상이 동작하지 않습니다.
  • ❌ 오류 2: Layout을 만들고도 표시 메서드에 안 넘기면 설정이 무시됩니다.

5. 실무에서 조심할 점 🚨

⚠️

"예쁘게"보다 "읽기 쉽게"

줄무늬·색상·너비 같은 외형 설정은 가독성을 위해 존재합니다. 색을 과하게 쓰거나 컬럼을 너무 좁/넓게 하면 오히려 보기 불편합니다. zebra와 cwidth_opt 정도만으로도 충분히 깔끔한 표가 됩니다. 색상은 "강조가 꼭 필요한 곳"에만 절제해서 쓰세요(M09).

6. 한눈에 정리 🏁

📝

오늘의 핵심만 딱 잡기

  • Layout(LVC_S_LAYO)은 표 전체의 외형을 정합니다.
  • zebra(줄무늬), cwidth_opt(자동 너비), info_fname(행 색상 필드)이 핵심.
  • info_fname에 적은 필드는 출력 테이블에 실제로 있어야 합니다.
  • 외형은 가독성을 위해 절제해서 사용합니다.
