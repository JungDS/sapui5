02 · 학습 관점

기술 이름보다 데이터 흐름을 먼저 잡는다

💡 핵심 마인드셋 초급자는 처음부터 약어를 외우기보다 업무 요청이 데이터 모델, 서비스, 화면으로 어떻게 바뀌는지 전체 파이프라인을 꿰뚫어 보는 것이 중요합니다.
  1. 1
    업무 요구사항

    구매오더, 판매오더, 전표 같은 업무 문서를 기준으로 요구사항이 나온다.

  2. 2
    데이터 모델

    Header/Item 구조, Key, 상태, 금액/수량 단위를 확인한다.

  3. 3
    데이터 가공 및 노출

    화면의 요구사항에 맞추어 Internal Table로 가공하거나, , , 을 통해 데이터를 외부로 노출한다.

  4. 4
    화면 구현

    ALV, , 중 가장 적합한 도구를 선택하여 데이터를 조회하고 조작하는 화면을 완성한다.

03 · 권장 순서

초심자에게 추천하는 학습 순서

  1. 1
    개발 환경과 도구

    SAP GUI, ADT, VS Code/BAS, Gateway Client, Browser DevTools의 역할을 구분한다.

  2. 2
    Classic ABAP 기본기

    실무에서 여전히 압도적으로 쓰이는 기반의 Report, Internal Table, Open SQL, ALV를 통해 서버와 화면 개발의 기본기를 확립한다.

  3. 3
    CDS와 OData

    데이터베이스의 데이터를 모델링하고, 웹 화면 등 외부에 로 노출하는 현대적 파이프라인을 익힌다.

  4. 4
    UI5 / Fiori Elements

    의 View, Controller, Model과 의 Annotation을 학습하여 엔터프라이즈 웹 화면을 완성한다.

  5. 5
    RAP

    가장 최신의 백엔드 프로그래밍 모델인 을 통해 S/4HANA 표준 개발 방식을 습득한다.
