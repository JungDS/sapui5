02 · 학습 흐름

이 순서로 배우면 막힘 없이 이어진다

Track 1의 큰 학습 단계입니다. 각 단계가 다음 단계의 토대가 됩니다.

  1. 1
    DDIC 데이터 구조

    Domain, Data Element, Structure, Transparent Table로 데이터의 그릇을 먼저 만든다.

  2. 2
    ABAP 문법과 입력

    기본 문법과 WRITE 출력, PARAMETERS 입력, DDIC 관계와 F4 Help를 익힌다.

  3. 3
    모듈화 & Internal Table

    코드를 나누어 호출하고, Internal Table로 데이터를 다루는 기초를 다진다.

  4. 4
    SALV & Open SQL 조회

    결과를 SALV로 바로 출력하고, 기본 조회 → SELECT-OPTIONS → JOIN/집계로 확장한다.

  5. 5
    View & Report Event

    Classic DDIC View와 유지보수 객체, 리포트 실행 이벤트와 입력 검증을 정리한다.

  6. 6
    Screen & Grid ALV

    Dynpro 화면 기초 위에 Grid ALV를 띄우고 Field Catalog, Layout, Variant를 익힌다.

  7. 7
    Modern ABAP & OO

    현대식 ABAP 문법과 New Open SQL, OO ABAP 기본 설계, ALV 표시 제어 심화로 나아간다.

  8. 8
    CDS & RAP / Cloud

    CDS View Entity로 의미 기반 모델링을 시작하고, RAP와 ABAP Cloud 입문으로 마무리한다.

➡️ 그다음은 Track 2 Track 1을 마치면 데이터 변경·동시성 제어, 인터페이스, 성능 튜닝, 운영 품질, RAP+Fiori Capstone 같은 실무 응용으로 확장합니다.
