01 · 로드맵 아웃라인

UI5/Fiori 개발을 체계적으로 정복하기 위한 이정표

SAPUI5는 단순한 화면 마크업 프레임워크가 아닌 완전한 Enterprise MVC 웹 애플리케이션 프레임워크입니다. 아래의 학습 단계를 따라 순차적으로 진행할 것을 추천합니다.

학습 단계주요 다루는 내용핵습 목표 및 지향점
1단계. JS 기초ES6+ 스펙, Scope, Promise/Async-Await 비동기 처리UI5 프레임워크 베이스가 되는 최신 자바스크립트 역량 확보
2단계. UI5 MVC 기본XML View, Controller 함수, 이벤트 바인딩, i18n 리소스화면 구성과 사용자의 동작을 연결하는 기본기 형성
3단계. OData 연동OData V2 Model, CRUD API 연동, Metadata 활용, JSON Model서버와 화면 데이터를 주고받고 바인딩하는 방법 습득
4단계. 네비게이션 & 레이아웃Routing, Flexible Column Layout, Fragment/Dialog웹앱 내 다중 화면 이동 및 레이아웃 제어
5단계. Fiori ElementsCDS Annotation, List Report, Object Page, Draft Handling템플릿 기반으로 코딩을 최소화한 신속한 표준 앱 개발
02 · 학습 팁

UI5 개발을 배울 때 항상 명심해야 할 포인트

바인딩 경로(Binding Path)에 대한 이해

UI5는 철저한 데이터 바인딩 기반입니다. `/{EntitySet}`(절대 경로)와 `{Property}`(상대 경로)의 차이를 이해하고 컨텍스트 흐름을 파악해야 데이터를 정상적으로 가져올 수 있습니다.

Browser DevTools와 UI5 Inspector

오류 메시지는 브라우저의 Console 탭과 Network 탭에 항상 출력됩니다. 크롬 확장의 UI5 Inspector를 사용해 컨트롤의 상태와 모델 데이터를 조회하는 습관을 들여야 합니다.

03 · 핵심 학습 체크리스트

다음 단계로 나아가기 위해 검증할 사항

  1. Controller 내에서 `this.getView().getModel()`을 통해 모델 인스턴스를 가져오고 쓸 수 있다.
  2. Manifest.json 파일 내의 Routing 타겟과 Pattern 설정을 직접 수정하여 화면 전환을 구현할 수 있다.
  3. OData 모델의 `read`, `create`, `update`, `remove` 메서드를 호출하고 Callback(Success/Error)을 활용할 수 있다.
