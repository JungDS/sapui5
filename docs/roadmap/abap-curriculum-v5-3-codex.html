ABAP 엔터프라이즈 커리큘럼 v5.3

처음 ABAP을 배우는 학습자가 기초 문법에서 RAP와 Fiori 실무까지 순서대로 확인할 수 있는 커리큘럼 목차입니다. 각 섹션은 이후 상세 수업 페이지로 연결될 예정이며, 이 페이지에서는 전체 학습 여정과 선후수 흐름을 먼저 잡습니다.

Stage 7 문서 온라인 과정 목차 34개 섹션 205개 학습 단위
01 · 과정 개요

ABAP 개발자로 성장하는 전체 여정을 먼저 펼쳐봅니다

이 커리큘럼은 초급자가 “무엇을 먼저 배우고, 다음에 무엇으로 이어지는지”를 놓치지 않도록 구성한 학습 지도입니다. 온라인 강의의 커리큘럼 화면처럼 큰 트랙, 섹션, 세부 수업 단위를 한눈에 보고 현재 위치를 확인할 수 있게 정리했습니다.

학습 트랙

2개

기본기를 다지는 흐름과 실무로 확장하는 흐름으로 나뉩니다.

커리큘럼 섹션

34개

각 섹션은 하나의 수업 묶음으로, 이후 상세 페이지의 입구가 됩니다.

세부 학습 단위

205개

개념 설명, 실습, 점검 항목으로 나누어 단계별로 학습합니다.

이 페이지를 읽는 방법 먼저 아래 학습 경로에서 큰 흐름을 확인한 뒤, 트랙별 섹션 카드에서 지금 필요한 학습 묶음을 선택합니다. 상세 수업 페이지가 추가되면 각 섹션 카드가 해당 페이지로 연결됩니다.
02 · 학습 경로

기초 객체에서 실무 앱까지 한 단계씩 올라갑니다

  1. 1
    DDIC와 기본 문법

    데이터 구조를 만들고 ABAP 프로그램의 가장 작은 실행 단위를 익힙니다.

  2. 2
    입력 화면과 메모리 데이터

    PARAMETERS, SELECT-OPTIONS, Internal Table을 연결해 사용자의 입력과 처리 결과를 다룹니다.

  3. 3
    Open SQL과 리포트

    DB 조회, JOIN, 집계, Report Event를 통해 업무 데이터를 읽는 흐름을 완성합니다.

  4. 4
    ALV와 화면 처리

    SALV, Screen Programming, Grid ALV로 조회 결과를 사용자가 다룰 수 있는 화면으로 만듭니다.

  5. 5
    Modern ABAP, OO, CDS, RAP

    최신 ABAP 표현, 객체지향 설계, 의미 기반 모델링, RAP 개발 흐름으로 확장합니다.

  6. 6
    실무 확장과 종합 실습

    Lock, Enhancement, Interface, 성능, 배포 품질, Fiori 실무 앱으로 마무리합니다.

03 · 트랙별 목차

트랙을 선택해 필요한 커리큘럼을 확인합니다

기본기를 처음부터 다지고 싶다면 트랙 1을, ABAP 기본기를 바탕으로 실무 주제를 확장하고 싶다면 트랙 2를 선택합니다. 이후 각 섹션 상세 페이지가 추가되면 이 목차 카드가 수업 페이지의 입구가 됩니다.

트랙 1

ABAP 기본 이론 및 구현 흐름

초급자가 DDIC, 문법, 입력, 데이터 처리, 조회, Report Event, SALV, Screen, Grid ALV, Modern ABAP, OO, CDS, RAP까지 선후수에 맞게 학습하는 트랙이다.

기본기 목차 처음 시작한다면 THEORY-01부터 순서대로 진행하는 것을 권장합니다. 이미 경험이 있다면 각 카드의 핵심 키워드로 비어 있는 부분을 먼저 확인하세요.
THEORY-016.0시간6개 단위

DDIC 1차: 기본 데이터 구조 생성

초급자가 SAP 데이터 객체의 최소 구성 단위를 만들고 Transparent Table까지 생성한다.

핵심 키워드: DDIC, SE11/ADT, Repository Object, Domain, Data Type

THEORY-026.0시간6개 단위

ABAP 기본 문법과 WRITE 출력

변수와 기본 제어 흐름을 이용해 실행 가능한 가장 작은 ABAP 프로그램을 작성한다.

핵심 키워드: REPORT, Comment, Activation, Execution, DATA

THEORY-033.2시간4개 단위

PARAMETERS 기반 Selection Screen 맛보기

복잡한 Selection Screen 이벤트 없이 단일 입력값을 받아 출력하는 흐름을 경험한다.

핵심 키워드: PARAMETERS, Screen Input, Elementary Input, DEFAULT, OBLIGATORY

THEORY-046.0시간6개 단위

DDIC 2차: 관계와 입력 도움말

PARAMETERS를 통해 입력 필드의 의미를 경험한 뒤 DDIC 관계와 F4 Help를 이해한다.

핵심 키워드: Foreign Key, Check Table, Cardinality, Value Table, Domain

THEORY-056.0시간6개 단위

ABAP 모듈화 기초

Internal Table 응용 전에 코드를 나누고 호출하는 최소 구조를 익힌다.

핵심 키워드: FORM, PERFORM, Subroutine, USING, CHANGING

THEORY-066.0시간6개 단위

Internal Table 기초

Internal Table의 존재 이유, 선언, 입력, 반복, 단건 조회 순서를 안정적으로 익힌다.

핵심 키워드: Internal Table, Runtime Memory, Application Server, Line Type, Work Area

THEORY-079.0시간9개 단위

Internal Table 응용과 Deep Structure 개념 소개

검색 이후 수정·삭제·정렬·성능 기초로 확장하고 Deep Structure는 개념 수준에서만 소개한다.

핵심 키워드: MODIFY, INDEX, TRANSPORTING, DELETE, WHERE

THEORY-084.0시간5개 단위

Simple ALV / SALV 1차

Internal Table 결과를 가장 단순한 SALV로 즉시 출력하여 데이터 처리의 결과를 시각화한다.

핵심 키워드: CL_SALV_TABLE, SALV, List Output, FACTORY, Changing Table

THEORY-096.0시간6개 단위

Open SQL 1차: 기본 조회

JOIN 전 단계로 단일 테이블 조회와 조건 조회를 익히고 결과를 Internal Table에 담는다.

핵심 키워드: SELECT FROM, FIELDS, ABAP SQL, WHERE, Host Variable @

THEORY-106.0시간6개 단위

SELECT-OPTIONS와 Range Table

Internal Table과 Open SQL 기본 조회 이후 Range 구조와 복수 입력 조건을 이해한다.

핵심 키워드: SIGN, OPTION, LOW, HIGH, SELECT-OPTIONS

THEORY-117.7시간7개 단위

Open SQL 2차: JOIN과 집계 조회

JOIN 개념을 중심으로 DB View와 CDS로 이어질 데이터 모델 사고를 만든다.

핵심 키워드: INNER JOIN, ON Condition, Alias, LEFT OUTER JOIN, Initial Value

THEORY-126.0시간6개 단위

Classic DDIC View와 유지보수 객체

Open SQL JOIN 직후 Classic View와 유지보수 객체를 학습해 CDS 전 비교 기준을 만든다.

핵심 키워드: Database View, Inner Join, DDIC View, Projection View, Field Restriction

THEORY-137.0시간7개 단위

ABAP Report Event와 Selection Screen 심화

DB 조회와 View까지 배운 뒤 리포트 실행 이벤트와 입력 검증 흐름을 정리한다.

핵심 키워드: LOAD-OF-PROGRAM, INITIALIZATION, START-OF-SELECTION, Default Value, AT SELECTION-SCREEN OUTPUT

THEORY-147.0시간7개 단위

Screen Programming / Dynpro 기초

Grid ALV 선행지식으로 Screen Painter, PBO/PAI, Custom Control의 기본 흐름을 익힌다.

핵심 키워드: Module Pool, Program Type M, Includes, Screen Number, Screen Painter

THEORY-159.0시간9개 단위

Grid ALV 기초

핵심 키워드: CL_GUI_CUSTOM_CONTAINER, Container Name, CL_GUI_ALV_GRID, Parent Container, Output Internal Table

THEORY-166.0시간6개 단위

THEORY-177.0시간7개 단위

핵심 키워드: Classic Open SQL, Modern ABAP SQL, FIELDS, @, Host Variable

THEORY-187.0시간7개 단위

트랙 2

05 · 상세 수업 안내

각 섹션은 별도 수업 페이지로 이어질 예정입니다

지금은 전체 커리큘럼의 목차와 학습 순서를 확인하는 페이지입니다. 이후 섹션별 상세 페이지가 추가되면 각 카드에서 개념 설명, 실습 흐름, 체크리스트, 다음 학습 연결을 더 깊게 다룹니다.

섹션 카드

수업 묶음의 제목, 예상 시간, 핵심 키워드를 빠르게 확인합니다.

상세 수업

각 섹션은 개념 이해, 작은 예제, 실습 과제, 오류 점검으로 확장됩니다.

다음 연결

수업을 마치면 바로 다음 섹션으로 넘어갈 수 있도록 학습 흐름을 유지합니다.

06 · 학습 체크

목차를 볼 때는 현재 위치와 다음 단계를 함께 확인합니다

  • 처음 시작한다면 트랙 1의 THEORY-01부터 순서대로 진행합니다.
  • 이미 ABAP 경험이 있다면 각 카드의 핵심 키워드로 부족한 구간을 먼저 찾습니다.
  • 트랙 2는 DDIC, Open SQL, ALV, OO ABAP 기초를 학습한 뒤 진행하는 것을 권장합니다.
  • 각 섹션에서는 개념 이해, 작은 실습, 오류 확인, 다음 섹션 연결을 함께 점검합니다.
  • 종합 실습에서는 CDS, RAP, Fiori Elements를 연결해 하나의 실무형 앱으로 마무리합니다.
