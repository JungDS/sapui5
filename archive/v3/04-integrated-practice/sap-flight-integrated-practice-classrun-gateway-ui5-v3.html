Flight 통합 실습 최신본

ClassRun, Gateway CRUD, UI5 연동, RAP BO까지 이어지는 실습을 최신본 중심으로 통합한다.

P0종합 실습본문 평서형실습 지시형
01 · 목표

하나의 Flight 시나리오로 ABAP과 UI5를 연결한다

이 실습은 단순 문법 문제가 아니라 데이터 모델, 서버 로직, OData, UI5 화면, 메시지 처리를 하나로 연결하는 종합 실습입니다.

02 · 단계

실습 단계

1
ClassRun KPI

Flight 데이터를 읽어 항공사/노선별 KPI를 출력한다.

2
Gateway CRUD

예약 또는 Alert 관리용 OData V2 서비스를 구현한다.

3
UI5 화면

목록/상세/저장 화면을 만들고 ODataModel로 연결한다.

4
Messaging

입력 오류와 백엔드 오류를 사용자에게 보여준다.

5
RAP 확장

동일 시나리오를 RAP BO로 재구성한다.

03 · 산출물

완료 기준

  • 실행 가능한 ABAP ClassRun
  • Gateway CRUD 서비스
  • UI5 List/Detail 앱
  • 입력 검증과 오류 처리
  • RAP로 확장 가능한 데이터 모델
