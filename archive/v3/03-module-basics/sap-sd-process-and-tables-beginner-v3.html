SD 프로세스와 주요 테이블 입문

판매오더, 납품, 출고, 청구와 문서 흐름을 개발자 관점에서 이해한다.

SD모듈 기초본문 평서형실습 지시형
01 · 프로세스

SD 기본 흐름

1
판매오더

고객, 자재, 수량, 가격, 납기를 입력한다.

2
납품

출고할 물류 문서를 생성한다.

3
출고

재고가 감소하고 회계/물류 흐름이 진행된다.

4
청구

고객에게 청구하고 회계 전표와 연결된다.

02 · 테이블

개발자가 먼저 알아야 할 테이블

구분테이블설명
판매오더VBAK, VBAPSales Order Header/Item
납품LIKP, LIPSDelivery Header/Item
청구VBRK, VBRPBilling Header/Item
문서흐름VBFASD 문서 간 연결
03 · 개발 관점

개발 요구사항은 이렇게 들어온다

  • 문서 상태를 조회하는 리포트
  • Header/Item 기준의 OData API
  • 특정 기간·조직·자재 기준의 집계
  • 오류 데이터 또는 미처리 문서 모니터링
