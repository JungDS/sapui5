UI5 Controller 함수 문법 입문

View와 Controller의 역할을 분리해서 이해하고, 버튼 클릭과 함수 실행 흐름을 초심자 기준으로 익힌다.

P0SAPUI5본문 평서형실습 지시형
01 · 시작하기

Controller는 화면의 행동을 담당한다

가 화면 구조라면, 는 사용자가 버튼을 눌렀을 때 무엇을 할지 정하는 파일입니다.

View

Input, Button, Table 같은 Control을 배치한다.

Controller

버튼 클릭, 입력 변경, 화면 초기화 같은 동작을 함수로 작성한다.

02 · 기본 구조

UI5 Controller 파일은 보통 이 모양입니다

Main.controller.js
sap.ui.define([
    "sap/ui/core/mvc/Controller",
    "sap/m/MessageToast"
], function (Controller, MessageToast) {
    "use strict";

    return Controller.extend("demo.controller.Main", {
        onInit: function () {
            // 화면이 처음 만들어질 때 실행됩니다.
        },

        onPressHello: function () {
            MessageToast.show("안녕하세요!");
        }
    });
});
03 · 이벤트

XML의 press와 Controller 함수가 연결된다

View와 Controller 연결
<!-- Main.view.xml -->
<Button text="확인" press=".onPressConfirm" />

// Main.controller.js
onPressConfirm: function () {
    sap.m.MessageToast.show("버튼을 눌렀습니다.");
}
04 · this

Controller 안의 this는 현재 Controller를 가리킵니다

를 통해 현재 화면의 View를 찾거나, 특정 ID의 Control을 가져올 수 있다.

Input 값 읽기
onCheckName: function () {
    var sName = this.byId("idNameInput").getValue();
    sap.m.MessageToast.show("입력한 이름: " + sName);
}
