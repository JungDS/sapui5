ABAP 개발자 경로

서버 개발과 OData/RAP 서비스를 구현하려는 학습자를 위한 순서이다.

  1. 1
    Classic ABAP 기본기

    Report, Selection Screen, Internal Table, Open SQL, ALV의 기본 흐름을 익힌다.

  2. 2
    ABAP New Syntax 입문

    DATA(...), VALUE, CORRESPONDING, FOR 등 실무 코드를 읽기 위한 신문법을 정리한다.

  3. 3
    CDS View에서 OData 노출까지

    ZI_* Interface View, ZC_* Projection View, Association, Service Binding 흐름을 학습한다.

  4. 4
    Gateway / OData V2 CRUD 입문

    SEGW, EntitySet, MPC/DPC, CRUD 메서드와 테스트 흐름을 이해한다.

  5. 5
    RAP End-to-End 입문

    RAP BO, Behavior Definition, Validation, Determination, Action, Service Binding을 연결한다.

  6. 6
    RAP Action 다건 선택 처리

    RAP Action 다건 선택 시 호출 단위와 Keys 일괄 전달 구조를 이해한다.

실무형 빠른 경로

핵심 개념을 빠르게 보고 통합 실습으로 넘어가는 경로이다.

  1. 1
    CDS View에서 OData 노출까지

    ZI_* Interface View, ZC_* Projection View, Association, Service Binding 흐름을 학습한다.

  2. 2
    Gateway / OData V2 CRUD 입문

    SEGW, EntitySet, MPC/DPC, CRUD 메서드와 테스트 흐름을 이해한다.

  3. 3
    SAPUI5 OData Model과 CRUD 입문

    JSONModel과 ODataModel, bindElement/bindItems, create/update/delete 흐름을 학습한다.

  4. 4
    Messaging과 Input Validation 실무 입문

    Input 화면 값과 Model 값의 차이, Messaging, 저장 Guard를 실습으로 이해한다.

  5. 5
    SAP Flight Model 데이터 구조 해설

    SCARR, SPFLI, SFLIGHT, SBOOK 등 Flight 모델 테이블 관계를 정리한다.

  6. 6
    Flight 통합 실습 최신본

    ClassRun, Gateway CRUD, UI5 연동, RAP BO까지 이어지는 종합 실습이다.
