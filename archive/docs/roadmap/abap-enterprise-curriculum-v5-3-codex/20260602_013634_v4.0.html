ABAP 엔터프라이즈 커리큘럼 v5.3

초급 ABAP 개발자가 실무형 SAP 개발자로 성장하기 위해 따라갈 수 있는 장기형 교육 목차이다. DDIC, 기본 문법, Internal Table, Open SQL, Selection Screen, ALV, Screen, OO ABAP, CDS, RAP, 실무 확장 기술까지 선후수 흐름에 맞게 정리한다.

Stage 7 문서 커리큘럼 포털 v5.3 배포자: 정훈영
01 · 개요

단순 ABAP 로드맵이 아니라 교육 운영용 커리큘럼입니다

이 페이지는 v5.3 커리큘럼의 전체 목차를 한눈에 보기 위한 상위 페이지이다. 각 섹션은 이후 별도 상세 페이지로 확장할 수 있도록 독립된 학습 단위로 정리되어 있다.

트랙

2개

기초 구현 흐름과 실무 응용 흐름으로 나눈다.

섹션

34개

선후수 기준으로 세분화된 학습 구간이다.

세부 학습 단위

205개

각 섹션의 상세 수업과 실습으로 확장된다.

운영 기준 이 페이지는 JSON 원문을 출력하는 문서가 아니다. 원본 데이터를 분석해 학습자가 읽을 수 있는 목차형 웹페이지로 재구성한 것이다.
02 · 설계 원칙

초급자가 무너지지 않도록 선후수를 촘촘하게 나눕니다

  1. DDIC는 테이블 생성, 관계/F4, Classic View/Maintenance View로 3단계 분리한다.
  2. PARAMETERS는 초반 맛보기로 두고 SELECT-OPTIONS는 Internal Table과 Open SQL 기본 조회 이후에 배치한다.
  3. SALV 1차는 Internal Table 응용 직후에 배치하고, Sort/Filter/Layout/Variant 심화는 OO ABAP 이후로 이동한다.
  4. Open SQL은 기본 조회와 JOIN/집계 조회 2단계로만 나누어 과도한 분산을 피한다.
  5. ABAP Report Event는 Classic DDIC View/Maintenance View 이후에 배치한다.
  6. Screen Programming은 Grid ALV의 선행 조건으로 Grid ALV 직전에 배치한다.
  7. Grid ALV 기초에는 Field Catalog, Layout, Variant, SET_TABLE_FOR_FIRST_DISPLAY까지 포함하되 Cell Color/Style은 심화로 미룬다.
  8. Deep Structure는 Internal Table 응용에서 개념 소개 후 ALV 표시 제어 심화에서 실제 구현한다.
  9. New Open SQL은 Modern ABAP Syntax 이후 별도 섹션으로 분리한다.
  10. Lock Object는 트랙 2 실무 데이터 변경/동시성 제어 영역에 둔다.

05 · 핵심 순서

가장 중요한 흐름은 DDIC에서 RAP까지 이어지는 사다리입니다

  1. 1
    DDIC와 기본 문법

    데이터 구조를 만들고 기본 출력과 입력을 경험한다.

  2. 2
    Internal Table과 SALV

    메모리 데이터를 다루고 즉시 화면으로 확인한다.

  3. 3
    Open SQL과 Selection Screen

    데이터 조회, Range Table, JOIN, 집계 흐름을 연결한다.

  4. 4
    Classic View, Report Event, Screen, Grid ALV

    전통적인 리포트와 화면 처리의 실행 흐름을 익힌다.

  5. 5
    Modern ABAP, OO, CDS, RAP

    최신 ABAP 개발 모델로 확장한다.

  6. 6
    실무 응용

    트랜잭션, Lock, Enhancement, Interface, 성능, 운영 품질, Capstone으로 완성한다.

06 · 운영 기준

한 페이지는 목차 포털로 두고, 상세 수업은 섹션별로 분리합니다

  • 이 페이지에서는 34개 섹션의 전체 흐름과 선후수만 확인한다.
  • 각 섹션의 205개 세부 학습 단위는 이후 개별 상세 페이지에서 다룬다.
  • 화면에는 한국어 설명만 사용하고, 기술 용어는 ABAP 개발자가 실제로 쓰는 명칭을 유지한다.
  • DDIC, Selection Screen, Open SQL, ALV, OO ABAP, CDS, RAP의 경계를 임의로 합치지 않는다.
  • 초급 과정에서는 사용법과 설계 심화를 분리해서 운영한다.
