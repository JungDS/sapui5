SAP 개발자 학습 로드맵

SAP 개발을 처음 배우는 학습자가 ABAP, UI5/Fiori, OData/RAP, 모듈 기초를 어떤 순서로 연결해야 하는지 단계별로 정리한다.

Stage 7 Docs 로드맵 초급자 기준 배포자: 정훈영
01 · 큰 그림

SAP 개발자는 기술과 업무를 함께 봐야 한다

SAP 개발 학습은 ABAP 문법만 익히는 것으로 끝나지 않는다. 화면은 SAPUI5나 Fiori Elements로 만들고, 데이터는 OData나 RAP으로 노출하며, 요구사항은 MM, SD, FI 같은 업무 프로세스에서 출발한다.

서버 개발

Classic ABAP, CDS, Gateway, RAP을 단계적으로 학습한다.

화면 개발

Freestyle SAPUI5와 Fiori Elements를 구분해 학습한다.

업무 이해

모듈 프로세스와 Standard Table 구조를 함께 익힌다.

02 · 학습 관점

기술 이름보다 데이터 흐름을 먼저 잡는다

초급자는 처음부터 약어를 외우기보다 업무 요청이 데이터 모델, 서비스, 화면으로 어떻게 바뀌는지 이해해야 한다.

1
업무 요구사항

구매오더, 판매오더, 전표 같은 업무 문서를 기준으로 요구사항이 나온다.

2
데이터 모델

Header/Item 구조, Key, 상태, 금액/수량 단위를 확인한다.

3
서비스 노출

CDS, Gateway, RAP 중 어떤 방식으로 데이터를 제공할지 결정한다.

4
화면 구현

UI5 또는 Fiori Elements에서 조회, 입력, 저장, 메시지를 구현한다.

03 · 권장 순서

초심자에게 추천하는 학습 순서

1
개발 환경과 도구

SAP GUI, ADT, VS Code/BAS, Gateway Client, Browser DevTools의 역할을 구분한다.

2
Classic ABAP 기본기

Report, Selection Screen, Internal Table, Open SQL, ALV로 서버 개발 기본기를 만든다.

3
CDS와 OData

DB 데이터를 모델링하고 UI나 외부 시스템에 노출하는 흐름을 익힌다.

4
SAPUI5 기본기

View, Controller, Model, Binding, Messaging을 연결한다.

5
RAP / Fiori Elements

S/4HANA 앱 개발 방식으로 확장한다.

04 · 트랙 선택

목표에 따라 학습 트랙을 선택한다

목표우선 학습이후 확장
ABAP 개발자Classic ABAP → ABAP New Syntax → CDSGateway → RAP → ABAP Cloud
UI5 개발자Controller → ODataModel CRUD → MessagingRouting → FCL → FLP
Fiori Elements 개발자CDS/RAP → Annotation → Service BindingList Report → Object Page → 배포
업무 개발자모듈 기초 → Standard Table MapFlight 통합 실습 → 실제 업무 시나리오
05 · 학습 완료 체크

다음 단계로 넘어가기 전에 확인한다

  1. ABAP, OData, UI5, RAP이 각각 어떤 위치의 기술인지 설명한다.
  2. 업무 요구사항이 모듈 프로세스와 Standard Table에서 출발한다는 점을 설명한다.
  3. Classic ABAP에서 RAP/Fiori Elements로 확장되는 큰 흐름을 설명한다.
  4. 본인의 목표 트랙을 하나 선택한다.
