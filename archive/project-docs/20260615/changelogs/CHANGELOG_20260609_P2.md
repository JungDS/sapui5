## Antigravity IDE (Gemini 3.1 Pro) 작업 상세 내용 (THEORY-01~10 보완)
- 사용자 지시에 따라 `THEORY-01` ~ `THEORY-10` 구간의 본문 텍스트 내 `THEORY-XX`를 `Chapter X`로, `MXX`를 `Lesson X`로 일괄 치환했습니다. (총 60여개 파일 대상, Node.js 스크립트 작성하여 안전하게 51개 파일의 텍스트만 치환 완료)
- 모든 ABAP 예제 코드 블록(`<pre><code>`)에 Shiki 포맷을 일괄 적용하여 가독성을 높이고 복사 버튼을 추가했습니다.
- 이미지 자산 관리 규칙 파일 `.project-docs/09_IMAGE_ASSETS_RULE.md`를 신규 생성하고, 파일명 네이밍 룰(`chXX-lesYY-01-설명.png`) 및 `THEORY-01` ~ `THEORY-10`에서 화면 캡처가 들어가면 좋을 만한 추천 위치를 정리했습니다.

## Antigravity 고민했던 점 및 설계 이유
- **대량 일괄 수정의 안정성**: 60여 개의 HTML 파일을 LLM이 수동으로 일일이 수정할 경우 누락이나 태그 파손의 위험이 매우 크기 때문에, `archive/_local/update_theory_01_10.mjs` 스크립트를 직접 작성해 태그 밖의 텍스트와 코드 블록만 정확하게 찾아서 치환하도록 설계했습니다.
- **초심자 분량 검증**: 이미 작성된 2~10단계를 확인한 결과 "왜 필요한가, 최소 예제, 오류 흐름, 한눈에 정리"가 평균 130줄 내외로 충실하게 갖춰져 있음을 판단하여 텍스트 포맷과 명칭 변경에만 집중했습니다.
- **이미지 규격화**: 향후 실습 이미지를 추가할 때 관리의 용이성을 위해 `09_IMAGE_ASSETS_RULE.md`에 명확한 명명 규칙을 남겼습니다.
