## 기록 규칙

- `Sample`은 원본 Academy/v3 샘플 경로 또는 v4 경로를 쓴다.
- `Pattern`은 재사용하려는 상호작용/표현 단위 이름을 짧게 쓴다.
- `Lessons`는 이 패턴을 실제 운영 Lesson에 적용한 Lesson ID 목록이다.
- `Count`는 `Lessons`의 개수다.
- `Decision`은 `local`, `watch`, `consider-v4`, `common-candidate`, `promoted` 중 하나를 쓴다.
- 같은 패턴이 3개 이상 Lesson에서 반복되면 `consider-v4` 또는 `common-candidate`로 올린다.
