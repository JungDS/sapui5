이곳은 AI 에이전트와 사용자가 함께 작업하며 고민했던 흔적, 설계 결정 과정, 그리고 매일매일의 세세한 개발 내역을 일기처럼 남기는 공간입니다.

## 📝 작성 규칙 (AI Agent Mandatory Rule)
1. 모든 AI 모델은 작업을 종료하기 전, **반드시** 해당 일자의 체인지로그 파일(예: `changelogs/CHANGELOG_YYYYMMDD.md`)을 생성하거나 수정하여, 오늘 수행한 작업의 상세 내용과 **고민했던 점(의사결정 이유, 기술적 한계 및 극복 방법 등)**을 기록해야 합니다.
2. 일자별 체인지로그 파일은 이 `.project-docs/changelogs` 폴더 내에 위치합니다.
3. 새로운 체인지로그 파일이 생성되면 아래 '일자별 기록 목록'에 링크를 추가해 주세요.
