1. **claim-before-start**: 어떤 Lesson이든 손대기 전에 `🔄 진행 중`에 행을 추가한다(이게 점유 신호다).
2. **한 Lesson = 한 AI**: `🔄 진행 중`에 이미 있는 Lesson은 다른 AI가 시작하지 않는다.
3. **종료 시 이동**: 완료하면 `🔄`에서 제거 → `✅ 완료 로그`에 1줄 + 챕터 표 갱신.
