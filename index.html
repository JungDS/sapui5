초급자 추천 경로

SAP 개발을 처음 배우는 학습자를 위한 순서입니다.

  1. 1
    SAP 개발자 학습 로드맵

    전체 학습 순서를 먼저 확인한다.

  2. 2
    SAP 개발 환경과 도구 입문

    SAP GUI, ADT, VS Code/BAS 등 도구 목적을 정리한다.

  3. 3
    ABAP 엔터프라이즈 커리큘럼

    Chapter와 Lesson 단위로 ABAP 전체 과정을 훑는다.

  4. 4
    SAP 모듈 기초와 개발자 관점

    업무 흐름과 테이블을 개발 관점에서 이해한다.

  5. 5
    Classic ABAP 기본기

    Report, Selection Screen, Internal Table, ALV를 익힌다.

실무형 빠른 경로

핵심 개념을 빠르게 보고 통합 실습으로 넘어가는 경로이다.

  1. 1
    CDS/RAP 전 ABAP 커리큘럼 후반부

    CDS와 RAP로 넘어가기 전 필요한 선행 Chapter를 확인한다.

  2. 2
    CDS View에서 OData 노출까지

    데이터 모델과 OData 노출 흐름을 확인한다.

  3. 3
    Gateway / OData V2 CRUD 입문

    SEGW, EntitySet, DPC_EXT, CRUD 흐름을 이해한다.

  4. 4
    SAPUI5 OData Model과 CRUD 입문

    ODataModel을 화면과 연결한다.

  5. 5
    Flight 통합 실습 최신본

    ABAP, Gateway, UI5를 하나의 실습으로 연결한다.
