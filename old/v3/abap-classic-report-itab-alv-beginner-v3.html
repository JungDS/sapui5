Classic ABAP 기본기

Report, Selection Screen, Internal Table, Open SQL, ALV의 기본 흐름을 하나의 개발 사이클로 이해한다.

P0Classic ABAP본문 평서형실습 지시형
01 · 역할

Classic ABAP은 여전히 기본기입니다

은 Report, Selection Screen, Internal Table, ALV 같은 전통적인 서버 개발 패턴을 의미한다. 최신 을 배우더라도 데이터 조회, 구조화, 디버깅 기본기는 Classic ABAP에서 시작된다.

02 · 기본 흐름

Report 프로그램의 전형적인 흐름

1
입력 받기

Selection Screen에서 조건을 입력받습니다.

2
데이터 조회

Open SQL로 필요한 컬럼만 조회한다.

3
내부 테이블 가공

Internal Table에서 정렬, 필터, 집계를 수행한다.

4
출력

ALV 또는 콘솔로 결과를 보여준다.

03 · 코드

초급자용 Report 뼈대

Report 기본 구조
REPORT zr_demo_flight.

SELECT-OPTIONS so_carr FOR sflight-carrid.

START-OF-SELECTION.
  SELECT carrid, connid, fldate, price, currency
    FROM sflight
    WHERE carrid IN @so_carr
    INTO TABLE @DATA(lt_flight).

  cl_demo_output=>display( lt_flight ).
04 · 체크리스트

처음부터 습관화할 기준

  1. SELECT *를 지양한다.
  2. LOOP 안 SELECT를 피한다.
  3. 입력, 조회, 가공, 출력을 함수나 메서드로 분리한다.
