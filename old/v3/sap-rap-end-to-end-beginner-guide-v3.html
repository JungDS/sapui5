RAP End-to-End 입문

Business Object, Behavior Definition, Validation, Determination, Action, Service Binding까지 전체 흐름을 익힌다.

P0RAP본문 평서형실습 지시형
01 · 정의

RAP은 S/4HANA의 현대적 비즈니스 객체 개발 방식이다

에서는 데이터 구조를 로 정의하고, 동작은 Behavior Definition/Implementation으로 선언하고 구현한다.

02 · 구성요소

RAP BO를 구성하는 핵심 요소

요소역할초급자 해석
Root View Entity비즈니스 객체의 데이터 구조어떤 데이터를 다루는가
Behavior Definition가능한 동작 선언생성/수정/삭제/액션 가능 여부
Behavior Implementation동작의 실제 로직검증, 계산, 액션 구현
Service BindingOData 노출화면/외부에서 호출 가능하게 함
03 · 확장

Validation, Determination, Action

1
Validation

저장 전에 데이터가 맞는지 검사한다.

2
Determination

특정 값이 바뀌면 다른 값을 자동 계산한다.

3
Action

승인, 취소, 상태변경처럼 명시적인 업무 버튼을 구현한다.
