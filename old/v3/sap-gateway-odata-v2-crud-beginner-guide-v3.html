Gateway / OData V2 CRUD 입문

SEGW 기반 OData V2 서비스에서 EntitySet, MPC/DPC, CRUD 메서드와 오류 처리를 이해한다.

P0Gateway본문 평서형실습 지시형
01 · 역할

Gateway는 SAP 데이터를 HTTP API로 열어주는 관문입니다

개발에서는 Entity, EntitySet, Association을 정의하고 DPC_EXT 메서드에서 조회/생성/수정/삭제 로직을 구현한다.

02 · CRUD

CRUD 메서드가 각각 맡는 일

동작대표 메서드의미
조회 목록GET_ENTITYSET여러 건 조회
단건 조회GET_ENTITY키 기준 1건 조회
생성CREATE_ENTITY새 데이터 생성
수정UPDATE_ENTITY기존 데이터 변경
삭제DELETE_ENTITY기존 데이터 삭제
03 · 테스트

테스트는 응답 구조까지 봐야 한다

초급자 주의HTTP 200만 보면 안 된다. 응답 Body, Error Message, Entity Key, Deep Structure가 의도대로 나오는지 확인해야 한다.
