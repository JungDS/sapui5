RAP Action 다건 선택 처리

RAP Action에서 다건 선택 시 호출 단위와 Keys 일괄 전달 구조를 이해한다.

P2RAP본문 평서형실습 지시형
01 · 문제상황

여러 행을 선택했을 때 Action은 몇 번 호출될까요?

UI에서 여러 행을 선택해 Action 버튼을 누르면, 프레임워크 설정에 따라 건별 호출처럼 보일 수도 있고, 여러 Key가 한 번에 전달될 수도 있다. 실무에서는 이 차이를 이해해야 성능과 트랜잭션 처리를 설계할 수 있다.

02 · Keys

다건 처리는 Keys 테이블을 기준으로 생각한다

개념 예시
METHOD approve.
  LOOP AT keys INTO DATA(ls_key).
    " 선택된 각 인스턴스 처리
  ENDLOOP.
ENDMETHOD.
03 · 확인

테스트 시 볼 것

  1. Action 구현 메서드가 몇 번 호출되는지 확인한다.
  2. keys에 몇 건이 들어오는지 확인한다.
  3. 성공/실패 메시지가 건별로 구분되는지 확인한다.
