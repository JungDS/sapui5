ABAP, Gateway, UI5 오류를 어디서부터 확인할지 초급자용 루틴으로 정리한다.

P1트러블슈팅본문 평서형실습 지시형
01 · 오류 위치

오류는 먼저 위치를 나눠야 한다

증상우선 확인 위치대표 도구
ABAP 로직 결과가 이상함서버 로직ADT Debugger
OData 호출 실패Gateway / HTTP 응답Gateway Client, Network
화면 버튼이 작동 안 함UI5 ControllerBrowser Console
Input 오류 표시가 이상함Binding / MessagingMessageModel, Support Assistant
02 · 루틴

실무에서 쓰는 기본 확인 순서

1
재현 조건 고정

어떤 입력값과 어떤 버튼에서 문제가 나는지 먼저 고정한다.

2
브라우저 Network 확인

요청이 서버까지 갔는지, HTTP 상태가 무엇인지 확인한다.

3
서버 로그 확인

Gateway Error Log 또는 ABAP Debugger로 서버 오류를 확인한다.

4
UI5 바인딩 확인

Control ID, binding path, MessageModel을 확인한다.

03 · UI5 콘솔

콘솔 확인은 임시 진단용으로 사용한다

브라우저 콘솔 예시
// 실제 런타임 ID를 알 때만 사용합니다.
sap.ui.getCore().byId("application-...--idInput").getBinding("value").getPath();

// Controller 내부에서는 보통 this.byId("idInput")을 우선 사용합니다.
