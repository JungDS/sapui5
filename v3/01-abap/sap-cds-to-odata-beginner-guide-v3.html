CDS View에서 OData 노출까지

ZI_* Interface View, ZC_* Projection View, Association, Annotation, Service Definition/Binding 흐름을 학습한다.

P0CDS/OData본문 평서형실습 지시형
01 · 레이어

CDS는 보통 Interface와 Projection으로 나눕니다

원천 테이블을 안정적인 재사용 모델로 감쌉니다. 예: ZI_Flight

화면이나 API 소비자에게 보여줄 필드와 의미를 정리한다. 예: ZC_Flight

02 · 흐름

CDS에서 OData까지

1
ZI_* Interface View

테이블과 Join/Association을 기반으로 안정적인 데이터 모델을 만든다.

2
ZC_* Projection View

소비자에게 필요한 필드와 Annotation을 정리한다.

3
Service Definition

노출할 View를 서비스 단위로 묶는다.

4
Service Binding

OData V2/V4 방식으로 실제 노출하고 테스트한다.

03 · 예시

Flight 모델 예시 이름

CDS 이름 예시
ZI_Flight          " Interface View
ZC_Flight          " Projection View
ZUI_FlightService  " Service Definition
ZUI_FLIGHT_O4      " Service Binding
