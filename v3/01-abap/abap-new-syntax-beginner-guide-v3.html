ABAP New Syntax 입문

DATA(...), VALUE, CORRESPONDING, FOR, REDUCE 등 실무 코드를 읽기 위한 신문법을 익힌다.

P1ABAP본문 평서형실습 지시형
01 · 필요성

New Syntax는 코드를 짧게 만들지만 처음에는 낯섭니다

초급자는 먼저 기존 문법과 신문법이 같은 의미라는 것을 연결해야 한다. 신문법을 무작정 외우기보다 실무 코드 읽기 능력을 목표로 삼습니다.

02 · 패턴

가장 자주 보는 패턴

문법의미초급자 해석
DATA(lv_name)인라인 변수 선언그 자리에서 변수를 만든다
VALUE #( ... )값 생성구조나 테이블 값을 한 번에 만든다
CORRESPONDING #( ... )같은 이름 필드 매핑필드명이 같은 것끼리 옮긴다
FOR ... IN ...반복식테이블을 돌며 새 값을 만든다
03 · 코드

기존 문법과 신문법 비교

New Syntax 예시
" 기존 방식
DATA ls_result TYPE ty_result.
ls_result-carrid = ls_flight-carrid.
ls_result-connid = ls_flight-connid.

" New Syntax
DATA(ls_result2) = VALUE ty_result(
  carrid = ls_flight-carrid
  connid = ls_flight-connid
).
