SAP 개발 환경과 도구 입문

SAP GUI, ADT, VS Code/BAS, Gateway Client, Browser DevTools가 각각 어떤 상황에서 필요한지 정리한다.

01 · 도구 지도

도구를 먼저 알면 실습 중 길을 잃지 않습니다

도구주 용도처음 배울 때의 관점
SAP GUI전통 SAP 화면, T-Code 실행표준 테이블 조회, 설정 확인, Gateway 로그 확인
ADT / EclipseABAP, CDS, RAP 개발ClassRun, CDS View, Behavior 구현
BAS / VS CodeUI5 앱 개발XML View, Controller, npm/ui5 tooling
Gateway ClientOData V2 테스트요청/응답과 HTTP 상태 확인
Browser DevToolsUI5 화면 디버깅Network, Console, 바인딩 경로 확인
02 · 실습 흐름

개발 흐름에 따라 도구가 바뀝니다

1
ABAP 로직 작성

ADT에서 Class, CDS, RAP Behavior를 작성한다.

2
서비스 노출

Gateway 또는 Service Binding으로 OData를 노출한다.

3
API 테스트

Gateway Client나 브라우저 Network에서 응답을 확인한다.

4
UI 구현

BAS/VS Code에서 SAPUI5 화면을 구현한다.

5
통합 디버깅

ABAP Debugger와 Browser DevTools를 함께 사용한다.

03 · 초심자 팁

처음에는 도구를 깊게 외우지 않아도 된다

학습 팁도구 이름을 외우기보다 “어디에서 문제가 났는가?”를 기준으로 선택하세요. 서버 로직이면 ADT, OData 응답이면 Gateway Client/Network, 화면 동작이면 Browser DevTools입니다.
