SAPUI5 데이터 흐름과 Messaging 아키텍처

SAPUI5 데이터 흐름과 Messaging을 개념형 참고자료로 정리한다.

참고SAPUI5본문 평서형실습 지시형
01 · 관점

데이터 흐름은 화면·모델·서버 세 층으로 본다

1
화면

Input, Table, Button 같은 Control이 사용자와 만납니다.

2
모델

JSONModel 또는 ODataModel이 데이터를 보관하거나 서버와 연결한다.

3
서버

OData/RAP/Gateway가 실제 업무 데이터를 제공한다.

02 · 메시지

Messaging은 오류를 사용자가 이해할 수 있게 연결한다

은 프론트엔드 검증 오류와 서버 메시지를 수집하고, 을 통해 화면에 보여줄 수 있게 한다.
