Fiori Launchpad 배포와 Semantic Object 입문

Tile, Target Mapping, Semantic Object, Action, Catalog/Space/Page, 권한 연결의 기본 흐름을 이해한다.

P1FLP본문 평서형실습 지시형
01 · 역할

Fiori Launchpad는 사용자가 앱을 실행하는 출발점입니다

UI5 앱을 만들었다고 사용자가 바로 볼 수 있는 것은 아닙니다. Launchpad에 타일, Target Mapping, 권한을 연결해야 한다.

02 · Semantic Object

Semantic Object와 Action은 의도를 표현한다

요소예시의미
Semantic ObjectSalesOrder무엇에 대한 앱인가
Actiondisplay, manage어떤 동작인가
Intent#SalesOrder-manageLaunchpad가 해석하는 실행 의도
03 · 흐름

배포 후 확인 순서

1
앱 배포

UI5 앱을 ABAP Repository 또는 BTP에 배포한다.

2
타일/Target Mapping

Launchpad에서 실행 의도를 연결한다.

3
Catalog/Space/Page

사용자에게 보일 메뉴 구조에 배치한다.

4
권한

역할을 통해 사용자가 접근할 수 있게 한다.
