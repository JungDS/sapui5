Messaging과 Input Validation 실무 입문

Input 화면 값과 Model 값의 차이를 직접 실습하고, Messaging과 저장 전 Guard까지 초심자 기준으로 이해한다.

01 · 먼저 해보는 실습

Input 값은 바뀌었는데 Model 값은 왜 그대로일까요?

아래 실습은 런타임을 흉내 낸 시뮬레이터입니다. abc, 999, 30을 차례로 눌러 보며 화면 값과 확정값의 차이를 확인한다.

실습 입력창

조건은 Integer, minimum: 1, maximum: 120입니다. 초기 Model 값은 20입니다.

현재 상태

Input 화면 값
20
Model 확정값
20

03 · 표준 코드

1.120 기준으로도 Messaging 중심 예제가 좋다

View.view.xml
<Input
    id="idAgeInput"
    valueLiveUpdate="true"
    value="{
        path: 'view>/Age',
        type: 'sap.ui.model.type.Integer',
        constraints: {
            minimum: 1,
            maximum: 120
        }
    }" />
Controller 저장 전 Guard
var bHasError = Messaging
    .getMessageModel()
    .getData()
    .some(function (oMessage) {
        return oMessage.type === MessageType.Error;
    });

if (bHasError) {
    MessageBox.error("입력 오류를 먼저 수정해 주세요.");
    return;
}
