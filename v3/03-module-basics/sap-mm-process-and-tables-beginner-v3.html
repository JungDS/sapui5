MM 프로세스와 주요 테이블 입문

구매요청, 구매오더, 입고, 송장 검증의 흐름과 주요 테이블을 개발자 관점으로 이해한다.

MM모듈 기초본문 평서형실습 지시형
01 · 프로세스

MM 기본 흐름

1
구매요청

현업 또는 MRP가 필요한 자재를 요청한다.

2
구매오더

공급업체, 자재, 수량, 가격, 납기를 확정한다.

3
입고

자재가 들어오면 재고가 증가하고 물류 문서가 생성된다.

4
송장 검증

공급업체 청구와 구매/입고 정보를 대조한다.

03 · 개발 관점

개발 요구사항은 이렇게 들어온다

  • 문서 상태를 조회하는 리포트
  • Header/Item 기준의 OData API
  • 특정 기간·조직·자재 기준의 집계
  • 오류 데이터 또는 미처리 문서 모니터링
