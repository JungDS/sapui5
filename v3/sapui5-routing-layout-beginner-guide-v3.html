SAPUI5 Routing과 Layout 입문

manifest routing, targets, List/Detail 이동, FlexibleColumnLayout의 기본 구조를 이해한다.

P1Routing본문 평서형실습 지시형
01 · 역할

라우팅은 화면 이동의 약속입니다

사용자가 목록에서 항목을 누르면 상세 화면으로 이동한다. 이때 URL, 패턴, 대상 View를 연결하는 장치가 Routing입니다.

02 · 구성요소

routes와 targets를 구분한다

구성역할
routes어떤 URL 패턴에서 어떤 target을 보여줄지 정의
targets실제로 표시할 View와 배치 위치 정의
Router현재 URL을 보고 맞는 화면을 찾아줌
03 · Layout

FlexibleColumnLayout은 여러 컬럼을 가진 앱에 적합한다

학습 팁처음에는 OneColumn → TwoColumnsMidExpanded 정도의 흐름만 이해하고, 이후에 3컬럼과 SemanticHelper로 확장하세요.
