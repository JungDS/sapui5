MRP 학생 배포용 학습 패키지

수요, 재고, 조달 제안을 연결해 MRP의 기본 목적과 결과 해석을 학습한다.

PP/SCMMRP본문 평서형실습 지시형
01 · 목적

MRP는 부족해지기 전에 조달 제안을 만든다

는 수요와 현재 재고를 비교해 언제 무엇을 구매하거나 생산해야 하는지 제안하는 과정입니다.

02 · 흐름

MRP의 기본 흐름

1
수요 확인

판매오더, 예측, 계획 독립 소요량을 확인한다.

2
재고/입고 예정 확인

현재 재고와 예정 입고를 반영한다.

3
부족 계산

필요 수량과 시점을 계산한다.

4
조달 제안 생성

구매요청 또는 계획오더를 생성한다.

  2. 현재 재고와 안전재고가 반영되었는가?
  3. 리드타임과 Lot Size가 의도대로 작동하는가?
