SAP 개발자 학습 로드맵

SAP 개발을 처음 배우는 학습자가 ABAP, UI5/Fiori, OData/RAP, 모듈 기초를 어떤 순서로 연결해야 하는지 단계별로 정리한다.

P0 입문 초급자 경로 예상 30~40분
01 · 큰 그림

SAP 개발자는 기술과 업무를 함께 봐야 한다

SAP 개발 학습은 문법만 익히는 것으로 끝나지 않는다. 화면은 나 로 만들고, 데이터는 나 으로 노출하며, 요구사항은 , , 같은 모듈 업무에서 나온다.

서버 개발

, , , 을 단계적으로 학습한다.

화면 개발

Freestyle SAPUI5와 Fiori Elements를 구분해 학습한다. Freestyle은 직접 구현 중심이고, Fiori Elements는 메타데이터 기반 생성 중심이다.

업무 이해

MM, PP, SD, FI, CO의 주요 프로세스와 Standard Table 구조를 익힌다. 개발자는 요구사항이 어느 업무 문서에서 출발했는지 알아야 한다.

02 · 학습 관점

기술 이름보다 데이터 흐름을 먼저 잡는다

초급자는 처음부터 모든 약어를 외우려 하기 쉽다. 하지만 SAP 개발은 약어 암기보다 “업무 요청이 데이터 모델과 화면으로 어떻게 바뀌는가”를 이해하는 것이 중요하다.

1
업무 요구사항

사용자가 구매오더, 판매오더, 생산오더, 회계전표 같은 업무 문서를 기준으로 요구사항을 말한다.

2
데이터 모델

개발자는 Header/Item 구조, Key 필드, 상태 필드, 금액/수량 단위를 확인한다.

3
서비스 노출

CDS, Gateway, RAP 중 어떤 방식으로 데이터를 외부나 UI에 제공할지 결정한다.

4
화면 구현

UI5 또는 Fiori Elements에서 조회, 입력, 저장, 오류 메시지 처리 흐름을 구현한다.

03 · 권장 순서

초심자에게 추천하는 학습 순서

1
개발 환경과 도구

SAP GUI, ADT, VS Code/BAS, Gateway Client, Browser DevTools가 각각 언제 쓰이는지 파악한다.

2
Classic ABAP 기본기

Report, Selection Screen, Internal Table, Open SQL, ALV로 서버 개발 기본기를 만든다.

3
CDS와 OData

DB에서 데이터를 모델링하고 UI나 외부 시스템에 노출하는 흐름을 학습한다.

4
SAPUI5 기본기

View, Controller, Model, Binding, ODataModel, Messaging을 연결한다.

5
RAP / Fiori Elements

현대 S/4HANA 앱 개발 방식으로 확장한다. Behavior, Service Binding, Annotation의 역할을 연결한다.

6
모듈 기초

개발 요구사항을 이해하기 위해 MM, PP, SD, FI, CO 프로세스와 주요 테이블을 학습한다.

04 · 트랙 선택

목표에 따라 학습 트랙을 선택한다

목표 우선 학습 이후 확장
ABAP 개발자 Classic ABAP → ABAP New Syntax → CDS Gateway → RAP → ABAP Cloud
UI5 개발자 Controller → ODataModel CRUD → Messaging Routing → FCL → Fiori Launchpad
Fiori Elements 개발자 CDS/RAP → Annotation → Service Binding List Report → Object Page → FLP 배포
업무 개발자 모듈 기초 → Standard Table Map Flight 통합 실습 → 실제 업무 시나리오 적용
05 · 학습 완료 체크

다음 단계로 넘어가기 전에 확인한다

  1. ABAP, OData, UI5, RAP이 각각 어떤 위치의 기술인지 설명한다.
  2. 업무 요구사항이 모듈 프로세스와 Standard Table에서 출발한다는 점을 설명한다.
  3. Classic ABAP에서 RAP/Fiori Elements로 확장되는 큰 흐름을 설명한다.
  4. 본인의 목표가 ABAP, UI5, Fiori Elements, 모듈 이해 중 어디에 가까운지 선택한다.
