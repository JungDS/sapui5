Classic ABAP Report / Internal Table / ALV 입문

SAP 개발의 첫 기본기는 조건을 입력받고, 데이터를 조회하고, Internal Table에 담은 뒤, ALV로 출력하는 흐름을 이해하는 것이다.

P0핵심 문서초급자 기준Stage 6
01 · 큰 그림

Classic ABAP Report는 조회형 프로그램의 기본 흐름이다

Classic ABAP Report는 사용자가 Selection Screen에서 조건을 입력하고, ABAP 프로그램이 DB에서 데이터를 조회한 뒤, Internal Table에 담아 가공하고, 최종 결과를 ALV로 보여주는 구조다.

1
조건 입력

PARAMETERS와 SELECT-OPTIONS로 조회 조건을 입력한다.

2
DB 조회

Open SQL로 필요한 데이터를 읽는다.

3
Internal Table 처리

LOOP, READ, MODIFY, APPEND로 데이터를 처리한다.

4
ALV 출력

결과 데이터를 표 형태로 출력한다.

02 · Report 구조

Report Program은 이벤트 블록을 기준으로 읽는다

조회형 Report에서는 Selection Screen 정의, START-OF-SELECTION, 데이터 조회, 출력 호출 순서가 핵심이다.

REPORT z_demo_flight_report.

TABLES: sflight.

PARAMETERS p_carrid TYPE sflight-carrid.
SELECT-OPTIONS s_fldate FOR sflight-fldate.

START-OF-SELECTION.
  "1. 조건 기준으로 데이터 조회
  "2. Internal Table 가공
  "3. ALV 출력
03 · Selection Screen

PARAMETERS와 SELECT-OPTIONS는 입력 조건을 만드는 도구다

구문용도예시
PARAMETERS단일 값을 입력받는다.항공사 코드 1개, 회사 코드 1개
SELECT-OPTIONS범위, 복수 값, 제외 조건을 입력받는다.기간, 전표번호 범위, 자재번호 목록
PARAMETERS p_carrid TYPE sflight-carrid OBLIGATORY.
SELECT-OPTIONS s_fldate FOR sflight-fldate.
04 · Internal Table

Internal Table은 ABAP 프로그램 내부의 작업용 데이터 집합이다

DB 테이블은 시스템에 저장된 원본 데이터이고, Internal Table은 ABAP 프로그램 안에서 처리하는 임시 데이터다.

TYPES: BEGIN OF ty_flight,
         carrid TYPE sflight-carrid,
         connid TYPE sflight-connid,
         fldate TYPE sflight-fldate,
         price  TYPE sflight-price,
       END OF ty_flight.

DATA gt_flight TYPE STANDARD TABLE OF ty_flight.
DATA gs_flight TYPE ty_flight.
05 · Open SQL

Open SQL은 필요한 데이터만 읽도록 작성한다

SELECT carrid,
       connid,
       fldate,
       price
  FROM sflight
 WHERE carrid = @p_carrid
   AND fldate IN @s_fldate
  INTO TABLE @gt_flight.
주의 실무 프로그램에서 조건 없는 SELECT는 피한다.
06 · 데이터 처리

LOOP, READ, MODIFY, APPEND는 Internal Table 처리의 기본 동작이다

구문역할초급자 관점
LOOP ATInternal Table 반복 처리전체 데이터 가공의 기본
READ TABLE조건에 맞는 한 행 검색키 기준 검색과 실패 처리 확인
MODIFY기존 행 변경대상 행을 명확히 지정
APPEND새 행 추가출력용 결과 테이블 생성
07 · ALV 출력

ALV는 조회 결과를 실무자가 읽을 수 있는 표로 보여준다

DATA go_alv TYPE REF TO cl_salv_table.

cl_salv_table=>factory(
  IMPORTING
    r_salv_table = go_alv
  CHANGING
    t_table      = gt_flight ).

go_alv->display( ).
08 · 초급자 실수

문법보다 데이터 흐름을 놓치는 실수가 더 많다

실수문제예방 방법
조건 없는 SELECT대량 조회와 성능 저하조건과 최대 조회 범위를 먼저 설계한다.
READ 실패 처리 누락빈 값 또는 이전 값 사용READ TABLE 후 결과 존재 여부를 확인한다.
ALV 출력만 확인조회/가공 오류를 놓침Debugger에서 SELECT 결과와 출력 전 데이터를 확인한다.
09 · 학습 완료 체크

다음 단계로 넘어가기 전에 확인한다

  1. Report Program의 기본 흐름을 입력 조건, 조회, 가공, 출력으로 설명한다.
  2. PARAMETERS와 SELECT-OPTIONS의 차이를 설명한다.
  3. Internal Table, Work Area, Structure의 차이를 설명한다.
  4. LOOP, READ, MODIFY, APPEND의 역할을 구분한다.
  5. Internal Table을 ALV로 출력하는 기본 코드를 읽는다.
