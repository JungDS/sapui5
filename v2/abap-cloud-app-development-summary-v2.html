ABAP Cloud App Development 정리

1. 현대 ABAP 개발 방향

SELECT → Internal Table → ALV → Web 확장

기존 방식은 ABAP에서 데이터를 가공한 후 화면에 출력하는 구조였습니다. 현재는 Code Push Down 개념을 기반으로 DB 레벨에서 최대한 처리하는 구조로 발전하였습니다.

2. Core Data Service (CDS)

  • Association (Join)
  • Aggregation (합계, 개수)
  • 통화/수량 환산
  • 계산 필드
  • Annotation 기반 UI 제어

CDS는 단순 조회가 아니라, DB View를 고도화한 모델링 기술입니다.

3. RAP (Restful Application Programming Model)

  • CRUD 지원
  • Draft (임시저장)
  • Validation
  • Determination
  • Action
  • Numbering

4. RAP 전체 구조

5. OData Service 구현 방식

① SAP GUI (SEGW) 방식

  • Data Model 정의
  • ABAP Class로 CRUD 직접 구현
  • RFC / Search Help / CDS 연결 가능

② CDS 기반 자동 서비스

  • @OData.publish: true
  • 조회 전용
  • /IWFND/MAINT_SERVICE 등록 필요

③ RAP 기반 서비스

  • CRUD 가능
  • Draft 가능
  • 비즈니스 로직 Class 구현
  • Cloud 표준 개발 모델

6. 실무 설계 방향

  • Master(기준정보) 테이블 설계
  • Transaction 테이블 설계
  • Data Element / Domain 명확화
  • CDS 기반 모델링
  • RAP 확장
