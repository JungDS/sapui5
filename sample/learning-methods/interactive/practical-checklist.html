실무 체크리스트

언제 쓰나

이 수단은 ABAP 개념을 텍스트로만 설명하면 실행 순서, 상태 변화, 실무 실수가 잘 보이지 않을 때 사용한다. 한 Lesson에는 핵심 수단 1개를 중심으로 두고, 실습이나 퀴즈와 연결하면 효과가 좋다.

샘플 컴포넌트

ABAP 예시 초안 3개

1. Internal Table 처리에 실무 체크리스트 적용

상황 여러 주문 행이 추가되고 LOOP에서 현재 행을 읽는 흐름을 초심자가 놓치지 않도록 보여준다.

초안 방향 데이터가 추가되기 전, 추가된 후, LOOP 중인 현재 행을 같은 화면에서 비교한다.

DATA lt_orders TYPE STANDARD TABLE OF zorder_demo.
APPEND VALUE #( order_id = 'SO-1001' amount = 120000 status = 'OPEN' ) TO lt_orders.
LOOP AT lt_orders INTO DATA(ls_order).
  WRITE: / ls_order-order_id, ls_order-status.
ENDLOOP.

2. Open SQL 조회에 실무 체크리스트 적용

상황 WHERE 조건, 조회 결과 없음, sy-subrc 확인처럼 자주 실수하는 지점을 학습자가 직접 확인한다.

초안 방향 정상 조회와 빈 결과를 나란히 보여주고 어떤 메시지가 나오는지 연결한다.

SELECT FROM zemployee_demo
       FIELDS employee_id, name, department
       WHERE department = @p_dept
       INTO TABLE @DATA(lt_employee).
IF sy-subrc <> 0.
  MESSAGE '조회 결과가 없습니다.' TYPE 'S'.
ENDIF.

3. Selection Screen 검증에 실무 체크리스트 적용

상황 입력값 검증이 메인 로직보다 먼저 실행된다는 런타임 순서를 체감하게 한다.

초안 방향 p_bukrs 입력 여부에 따라 AT SELECTION-SCREEN과 START-OF-SELECTION 로그가 달라진다.

PARAMETERS p_bukrs TYPE bukrs OBLIGATORY.
AT SELECTION-SCREEN.
  IF p_bukrs IS INITIAL.
    MESSAGE '회사 코드를 입력하세요.' TYPE 'E'.
  ENDIF.
START-OF-SELECTION.
  WRITE: / '회사 코드:', p_bukrs.

AI 작성 메모

초안 생성 시 먼저 학습자가 무엇을 관찰하거나 조작해야 하는지 정하고, 그 결과를 정답 해설이나 완료 조건과 연결한다. 과한 장식보다 코드, 데이터, 결과의 대응 관계가 선명해야 한다.
