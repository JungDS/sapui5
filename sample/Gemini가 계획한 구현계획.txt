# 학습 수단 샘플 라이브러리 v3 최종 구현 계획

`sample/learning-methods-v2`에 구축된 기존 38개 학습 수단에 **신규 기획된 6종의 고품질 상호작용 수단**을 추가하여 **총 44개**의 학습 수단 샘플 페이지를 생성합니다. 
모든 페이지는 최소 3개의 디자인 시안(Design Variants)을 제공하며, 브라우저에서 디자인 선택 즉시 Python API 서버를 통해 로컬 파일에 선택 결과가 기록됩니다. 기존 v2는 보존됩니다.

## User Review Required

> [!IMPORTANT]
> **1. B안 채택에 따른 로컬 서버(dev-server.py) 환경 및 작동 방식**
> - 저장소 루트(`c:\ui5\study\sapui5`)에 약 15라인의 `dev-server.py`가 생성됩니다.
> - 기존 `python -m http.server` 대신, 터미널에서 `python dev-server.py`를 실행합니다.
> - 브라우저 화면에서 디자인 시안(라디오 버튼)을 선택하면 즉시 백그라운드 API(POST)가 호출되어 `design-choices.json` 파일에 선택 결과가 자동 갱신됩니다.

> [!TIP]
> **2. 시안(Design Variants) 적용 형태**
> 각 44개 페이지 상단에 **디자인 시안(Design Variants) 섹션**을 추가합니다. 
> 사용자가 A, B, C 시안 중 하나를 클릭하면, 아래쪽 본문 예시 컴포넌트들의 레이아웃 및 스타일(색상, 테두리, 정렬 등)이 CSS 변수 및 클래스 토글을 통해 **즉각적으로 변화**하여 시각적인 차이를 직관적으로 비교할 수 있도록 구현합니다.

> [!TIP]
> **3. 🌟 (신규) 추가 확장되는 6가지 고품질 학습 수단 제안**
> 기존 38개에 얽매이지 않고, 강의 퀄리티를 대폭 끌어올릴 6가지 새로운 컴포넌트를 기획하여 v3에 추가합니다.
> 1. **`visuals/image-hotspot-explorer.html` (이미지 핫스팟 탐색기):** SAP GUI나 ADT의 스크린샷 이미지 위에 투명한 마우스 핫스팟을 두고, 마우스를 올리거나 클릭하면 해당 영역의 설정 툴팁이나 설명이 뜨는 양방향 UI.
> 2. **`visuals/interactive-data-chart.html` (인터랙티브 데이터 차트):** 테이블의 샘플 데이터를 수정하면 CSS/SVG 차트(막대/파이)가 실시간으로 변동하는 차트 컴포넌트. (ALV 대시보드나 실적 집계 학습용)
> 3. **`code-learning/performance-profiler-mock.html` (성능 프로파일러 모의 실험):** LOOP 내 SELECT(Bad)와 FAE/JOIN(Good) 코드의 성능 차이를, 가상의 프로파일러 게이지 바 애니메이션을 통해 속도(ms) 차이로 생동감 있게 보여주는 UI.
> 4. **`interactive/architecture-builder.html` (다단계 아키텍처 조립기):** TIER(DB, App, UI)에 맞춰 제공된 블록들을 마우스로 알맞은 영역에 드롭하면 점선이 연결되며 거대한 SVG 아키텍처가 완성되는 퍼즐. (RAP, OData 구조 설명용)
> 5. **`interactive/shortcut-simulator.html` (단축키 커맨드 시뮬레이터):** F8, Ctrl+F3 등 실제 ADT 키보드 단축키를 화면 내 가상 키보드 UI와 연동하여 타이핑하듯 배울 수 있는 시뮬레이터.
> 6. **`quizzes/ox-survival-quiz.html` (O/X 타임어택 서바이벌):** 간단하지만 빠른 판단이 필요한 ABAP 문법(예: `sy-subrc = 0` 의미 등)을 5초 이내에 O/X로 연달아 풀어야 하는 긴장감 있는 퀴즈 형태.
