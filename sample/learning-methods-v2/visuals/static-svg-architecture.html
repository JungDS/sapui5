정적 SVG 아키텍처

외부 이미지 없이 인라인 SVG로 계층·시스템 관계를 그립니다. 해상도에 무관하게 선명하고, 코드로 색·라벨을 제어할 수 있어 CDS·RAP·ALV 같은 구조 설명에 적합합니다. viewBox로 폭에 맞춰 자동 축소됩니다.

CDS / RAP 적용반응형 SVG

실제 적용 예시 3

같은 수단을 세 가지 아키텍처에 적용

예시 1 · CDS (VDM 계층)

Virtual Data Model 계층 구조

아래 계층(테이블 근접)에서 위 계층(소비)으로 갈수록 재사용·캡슐화가 강화됩니다.

AI 작성 메모: 계층 구조는 위→아래 추상도 순서를 색과 위치로 일관되게 두면 한눈에 읽힌다.

예시 2 · RAP

RAP 핵심 구성요소

CDS가 데이터를, Behavior가 동작을, Service가 노출을 담당하고 최종적으로 OData/Fiori로 소비됩니다.

AI 작성 메모: 구성요소가 많은 프레임워크는 "데이터·동작·노출" 같은 역할군으로 색을 묶으면 복잡도가 준다.

예시 3 · ALV

Grid ALV Container 계층

Grid ALV는 화면 → Container → Grid 순으로 중첩됩니다(SALV는 이 단계가 자동).

AI 작성 메모: 중첩 구조는 사각형을 겹쳐 그려 "안에 들어 있음(포함)"을 위치로 표현한다.
