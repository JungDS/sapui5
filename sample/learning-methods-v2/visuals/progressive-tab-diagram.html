탭형 점진 빌드업 다이어그램

복잡한 흐름을 한 번에 쏟아내지 않고, 탭을 누를 때마다 노드와 코드가 한 단계씩 늘어나는 방식입니다. 왼쪽엔 흐름도, 오른쪽엔 같은 단계의 ABAP 코드를 나란히 두어 추상 흐름과 실제 코드를 동시에 매핑합니다.

예시 2 · Open SQL

SELECT 쿼리 점진 빌드업

단순 전체 조회 → WHERE 필터 추가 → JOIN으로 확장하는 과정을 탭으로 나눠, 쿼리가 어떻게 정교해지는지 단계별로 보여줍니다.

Open SQL 조회문이 정교해지는 3단계

STEP 1
SELECT carrid, connid, fldate
  FROM sflight
  INTO TABLE @DATA(lt_flight).
" 모든 행을 가져온다 — 아직 조건이 없다
STEP 2
SELECT carrid, connid, fldate
  FROM sflight
  WHERE carrid = @p_carrid          " 필터 추가
  INTO TABLE @DATA(lt_flight).
STEP 3
SELECT f~carrid, c~carrname, f~fldate
  FROM sflight AS f
  INNER JOIN scarr AS c ON f~carrid = c~carrid
  WHERE f~carrid = @p_carrid
  INTO TABLE @DATA(lt_join).
AI 작성 메모: "단순 → 조건 → 결합"처럼 같은 코드가 누적될 때 탭이 가장 효과적이다. 탭마다 직전 단계와 달라진 줄만 강조하면 차이가 또렷해진다.

예시 3 · OO ABAP

클래스 정의 점진 빌드업

빈 클래스 골격 → 메서드 선언 → 인스턴스 생성/호출까지 탭으로 확장해, 클래스가 완성되는 과정을 단계별로 익힙니다.

로컬 클래스가 완성되는 3단계

STEP 1
CLASS lcl_report DEFINITION.
  PUBLIC SECTION.
ENDCLASS.

CLASS lcl_report IMPLEMENTATION.
ENDCLASS.
STEP 2
CLASS lcl_report DEFINITION.
  PUBLIC SECTION.
    METHODS run IMPORTING iv_year TYPE i.
ENDCLASS.

CLASS lcl_report IMPLEMENTATION.
  METHOD run.
    WRITE: / iv_year.
  ENDMETHOD.
ENDCLASS.
STEP 3
START-OF-SELECTION.
  DATA(lo_report) = NEW lcl_report( ).
  lo_report->run( iv_year = 2026 ).
AI 작성 메모: 객체 지향 입문에서 "선언 → 구현 → 사용" 3단계 탭은 한 화면에 전체 코드를 쏟아내는 것보다 인지 부하가 훨씬 낮다.
