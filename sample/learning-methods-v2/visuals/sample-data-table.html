샘플 데이터 테이블

작은 입력 데이터셋과 쿼리 결과셋을 함께 제시해, SQL·내부 테이블 연산이 데이터를 어떻게 거르고 합치는지 눈으로 확인시킵니다. 추상적 쿼리를 "이 데이터가 이렇게 바뀐다"로 구체화합니다.

Open SQL 적용원본 데이터 + 결과셋

실제 적용 예시 3

같은 수단을 세 가지 쿼리에 적용

예시 1 · Open SQL — WHERE 필터

WHERE carrid = 'AA'

원본 SFLIGHT
carridconnidprice
AA0017422
LH0400555
AA0064666
결과 (carrid='AA')
carridconnidprice
AA0017422
AA0064666

WHERE는 조건에 맞는 행만 남깁니다. LH 행은 결과에서 빠집니다.

AI 작성 메모: 원본과 결과를 같은 컬럼 구조로 두면 "어느 행이 걸러졌는가"가 즉시 보인다.

예시 2 · Open SQL — INNER JOIN

두 테이블 결합 결과

sflight + scarr
carrid(scarr) carrname
AAAmerican
LHLufthansa
JOIN 결과
carridcarrnamefldate
AAAmerican2026-07-01
LHLufthansa2026-07-02

JOIN은 carrid가 일치하는 행끼리 컬럼을 합칩니다. 코드 값(AA)이 이름(American)으로 풍부해집니다.

AI 작성 메모: JOIN은 "코드 → 이름"처럼 의미가 붙는 결과를 보여줘야 왜 결합하는지 와닿는다.

예시 3 · Open SQL — 집계

SUM ... GROUP BY carrid

원본 (행별 요금)
carridprice
AA422
AA666
LH555
집계 결과
carridSUM(price)
AA1088
LH555

GROUP BY는 같은 키의 행을 묶고, 집계 함수가 그 그룹을 하나의 값으로 요약합니다.

AI 작성 메모: 집계는 "여러 행 → 한 행"으로 줄어드는 모습을 표로 보여줄 때 GROUP BY 개념이 분명해진다.
