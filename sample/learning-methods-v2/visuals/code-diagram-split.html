코드/다이어그램 좌우 비교

왼쪽엔 흐름도, 오른쪽엔 그 흐름을 구현한 실제 ABAP 코드를 나란히 둡니다. 추상 개념과 구체 코드가 같은 화면에서 1:1로 매핑되어, "이 단계가 코드의 이 줄"임을 즉시 연결합니다. 좁은 화면에서는 자동으로 위아래로 쌓입니다.

원본: Chapter 13 Lesson 1 (탭 좌우 분할)흐름 ↔ 코드 매핑

실제 적용 예시 3

같은 수단을 세 가지 ABAP 주제에 적용

예시 1은 Chapter 13 Lesson 1의 다이어그램+에디터 좌우 분할 레이아웃을 이식했습니다.

예시 1 · Report Event (Chapter 13 Lesson 1 원본)

이벤트 흐름 ↔ 코드

flowchart TD INIT("
1

INITIALIZATION
") ASS("
2

AT SELECTION-SCREEN
") SOS("
3

START-OF-SELECTION
") INIT --> ASS ASS --> SOS style INIT fill:#ffffff,stroke:#eab308,color:#1e293b style ASS fill:#ffffff,stroke:#f472b6,color:#1e293b style SOS fill:#ffffff,stroke:#22c55e,color:#1e293b
ZREPORT_EVENT
INITIALIZATION.
  p_year = '2026'.

AT SELECTION-SCREEN.
  IF p_year IS INITIAL.
    MESSAGE '연도 입력!' TYPE 'E'.
  ENDIF.

START-OF-SELECTION.
  SELECT * FROM zemp WHERE gyear = @p_year INTO TABLE @gt.
AI 작성 메모: 다이어그램 노드 번호와 코드 블록 순서를 일치시키면 시선이 "1→1, 2→2"로 자연스럽게 흐른다.

예시 2 · Open SQL

JOIN 흐름 ↔ 코드

flowchart TD A("
sflight (f)
") B("
scarr (c)
") J("
결합

INNER JOIN
f~carrid = c~carrid
") A --> J B --> J style A fill:#ffffff,stroke:#0284c7,color:#1e293b style B fill:#ffffff,stroke:#0284c7,color:#1e293b style J fill:#ffffff,stroke:#22c55e,color:#1e293b
ZFLIGHT_JOIN
SELECT f~carrid, c~carrname, f~fldate
  FROM sflight AS f
  INNER JOIN scarr AS c
    ON f~carrid = c~carrid
  INTO TABLE @DATA(lt_join).
AI 작성 메모: JOIN처럼 "두 입력이 하나로 합쳐지는" 구조는 다이어그램이 ON 조건의 의미를 코드보다 빨리 전달한다.

flowchart TD L("

") W("
처리

행 처리
") E("

ZITAB_LOOP

AI 작성 메모: 반복은 다이어그램의 "되돌아가는 화살표"로 표현하면 ENDLOOP가 어디로 점프하는지 직관적이다.
