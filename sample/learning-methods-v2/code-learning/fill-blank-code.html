빈칸 코드 완성

핵심 키워드나 조건식을 빈칸으로 비워두고 직접 채우게 합니다. 정답을 입력하면 즉시 채점되어, 읽기만 하던 코드를 능동적으로 회수하게 만듭니다.

원본: Chapter 13 Lesson 1~6 (이벤트 키워드)입력 즉시 채점

실제 적용 예시 3

같은 수단을 세 가지 ABAP 코드에 적용

예시 1은 Chapter 13의 이벤트 블록 키워드를 빈칸으로 만든 문제입니다.

예시 1 · Report Event (Chapter 13 주제)

기본값을 채울 이벤트 블록은?

FILL
PARAMETERS p_date TYPE sy-datum.

________________.   " 빈칸: 기본값 세팅 이벤트
  p_date = sy-datum.
정답을 입력하고 채점을 눌러보세요.
AI 작성 메모: 정답이 한 단어(키워드)일 때 빈칸이 가장 깔끔하다. 힌트는 "어느 시점인지"를 떠올리게 적는다.

예시 2 · Open SQL

Strict 모드 호스트 변수 기호는?

FILL
SELECT * FROM sflight
  WHERE carrid = ___p_carrid   " 빈칸: 한 글자 기호
  INTO TABLE @lt.
정답을 입력하고 채점을 눌러보세요.
AI 작성 메모: 자주 빠뜨리는 한 글자(@) 같은 디테일은 빈칸으로 만들어 손에 각인시킨다.

예시 3 · Internal Table

이진 탐색에 꼭 필요한 선행 구문은?

FILL
____ lt_emp BY empno.   " 빈칸: 선행 정렬
READ TABLE lt_emp WITH KEY empno = '4000'
  BINARY SEARCH.
정답을 입력하고 채점을 눌러보세요.
AI 작성 메모: "전제 조건"을 빈칸으로 물으면 단순 암기를 넘어 의존 관계를 회수하게 된다.
