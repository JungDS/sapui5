코드 키워드 아코디언

코드 안의 핵심 키워드를 점선 앵커로 표시하고, 클릭하면 바로 그 줄 아래에서 설명 아코디언이 펼쳐집니다. 긴 예제를 떠나지 않고도 키워드 단위로 의미를 분해해 읽을 수 있습니다.

원본: Chapter 13 Lesson 1 (이벤트 키워드 투어) 클릭 → 인라인 펼침 코드 이탈 없음

실제 적용 예시 3

같은 수단을 세 가지 ABAP 코드에 적용

예시 1은 Chapter 13 Lesson 1의 이벤트 키워드 클릭 투어를 이식했습니다. 점선 키워드(🔍)를 클릭해 보세요.

예시 1 · Report Event (Chapter 13 Lesson 1 원본)

이벤트 블록 키워드 투어

코드는 거꾸로 배치돼 있지만 실행 순서는 INITIALIZATION → START-OF-SELECTION → END-OF-SELECTION입니다. 각 키워드를 눌러 실행 순위 설명을 확인하세요.

ZREPORT_EVENT_DEMO
1
REPORT zreport_event_demo.
2
3
START-OF-SELECTION. 🔍
[3순위 실행] START-OF-SELECTION

DB에서 데이터를 SELECT로 조회·가공하는 핵심 블록입니다. 비즈니스 로직은 여기에 둡니다.

4
WRITE: / '[3] START-OF-SELECTION 실행'.
5
END-OF-SELECTION. 🔍
[4순위 실행] END-OF-SELECTION

조회·연산이 끝난 뒤 결과를 출력하는 마감 블록입니다. 빈 결과 안내도 여기서 처리합니다.

6
WRITE: / '[4] END-OF-SELECTION 실행'.
7
INITIALIZATION. 🔍
[1순위 실행] INITIALIZATION

코드 가장 아래에 적혀 있어도 전체 흐름 중 가장 먼저(선택 화면 표시 전) 실행됩니다.

8
WRITE: / '[1] INITIALIZATION 실행'.
AI 작성 메모: "코드 위치 ≠ 실행 순서"처럼 직관에 어긋나는 개념일수록, 키워드 클릭 설명이 오개념을 즉시 교정한다.

예시 2 · Open SQL

SELECT 구문 절(clause) 투어

SELECT 한 문장을 이루는 절들을 키워드 단위로 분해합니다. 각 키워드를 눌러 역할을 확인하세요.

ZFLIGHT_SELECT
1
SELECT 🔍 carrid, connid, price
SELECT — 필드 목록

가져올 컬럼만 콕 집어 지정합니다. SELECT *보다 필요한 필드만 적는 것이 성능에 유리합니다.

2
FROM 🔍 sflight
FROM — 조회 대상

어떤 DB 테이블/뷰에서 읽을지 지정합니다.

3
WHERE 🔍 carrid = @p_carrid
WHERE — 필터 조건

조건에 맞는 행만 골라냅니다. 호스트 변수에는 @를 붙여야 합니다(Strict 모드).

4
INTO TABLE 🔍 @DATA(lt_flight).
INTO TABLE — 결과 담기

여러 행을 내부 테이블에 담습니다. 한 행만 받을 때는 INTO @DATA(...) + SELECT SINGLE을 씁니다.

AI 작성 메모: 한 문장이 여러 절로 이뤄진 구문(SELECT, LOOP, CALL METHOD)은 절 단위 아코디언으로 쪼개면 초보자 부담이 크게 준다.

예시 3 · Internal Table

READ TABLE 옵션 투어

내부 테이블 한 행 읽기 구문의 옵션을 키워드별로 분해합니다.

ZITAB_READ
1
READ TABLE 🔍 lt_emp INTO ls_emp
READ TABLE — 한 행 읽기

조건에 맞는 첫 번째 행을 Work Area로 복사합니다.

2
WITH KEY 🔍 empno = '1000'
WITH KEY — 검색 조건

어떤 값으로 찾을지 지정합니다. 키가 완전할수록 결과가 결정적입니다.

3
BINARY SEARCH 🔍.
BINARY SEARCH — 이진 탐색

빠르지만 반드시 사전에 같은 키로 SORT가 되어 있어야 합니다. 정렬이 안 되면 덤프 없이 잘못된 결과가 납니다.

4
IF sy-subrc = 0. 🔍
sy-subrc — 결과 확인

0이면 행을 찾은 것, 4면 못 찾은 것. 실패 시 Work Area에는 직전 값이 남아 있을 수 있어 반드시 확인해야 합니다.

AI 작성 메모: BINARY SEARCH의 "SORT 선행" 전제처럼 숨은 조건은 키워드 아코디언에서 경고로 강조하면 실수를 예방한다.
