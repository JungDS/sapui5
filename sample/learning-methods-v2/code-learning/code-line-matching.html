코드 라인 매칭

코드 줄과 그 역할(또는 실행 단계)을 연결하게 합니다. 왼쪽 코드(번호)와 오른쪽 설명(문자)을 짝지어 보고, 정답을 펼쳐 확인합니다. 복잡한 예제를 줄 단위 의미로 해부할 때 좋습니다.

예시 1 · Report Event (Chapter 13 주제)

이벤트 블록 ↔ 역할

1. INITIALIZATION.
2. AT SELECTION-SCREEN.

4. END-OF-SELECTION.

AI 작성 메모: 보기를 코드 순서와 다르게 섞어야(코드 1234 / 설명 CADB) 단순 위치 매칭이 아닌 의미 매칭이 된다.

예시 2 · Open SQL

SELECT 절 ↔ 의미

1. SELECT carrid, price
2. FROM sflight
3. WHERE carrid = @p_c
4. INTO TABLE @lt
A. 조회 대상 테이블
B. 가져올 컬럼 목록
C. 결과를 담을 내부 테이블
D. 필터 조건
정답 보기

1-B, 2-A, 3-D, 4-C

AI 작성 메모: 한 문장이 여러 절로 구성된 구문은 절 ↔ 역할 매칭으로 구조를 분해한다.
