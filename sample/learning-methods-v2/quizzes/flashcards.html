용어 플래시카드

카드를 클릭하면 앞면(용어)이 뒷면(뜻)으로 뒤집힙니다. 먼저 뜻을 떠올린 뒤 확인하는 반복 학습으로, 초반 DDIC·OO·RAP 용어 암기에 적합합니다.

같은 수단을 세 가지 용어 묶음에 적용

카드를 클릭해 뜻을 확인하세요. 예시 1은 Chapter 13 이벤트 용어입니다.

예시 1 · Report Event (Chapter 13 주제)

이벤트 용어 카드

INITIALIZATION화면 표시 전 기본값을 채우는 이벤트
AT SELECTION-SCREEN입력값을 검증하는 검문소 이벤트
START-OF-SELECTIONDB 조회 등 메인 로직 이벤트
END-OF-SELECTION결과를 출력·마감하는 이벤트
AI 작성 메모: 앞면은 용어, 뒷면은 한 문장 정의로 짧게. 길면 회수 효과가 떨어진다.

예시 2 · DDIC

DDIC 용어 카드

Domain타입·길이·값 범위 등 기술 속성 정의
Data Element의미·레이블을 부여하는 의미 계층
Check TableForeign Key가 참조하는 유효값 마스터
Search HelpF4 입력 도움말을 제공하는 객체
AI 작성 메모: 위계가 있는 용어(Domain→Data Element)는 카드 순서를 위계대로 배치한다.

예시 3 · RAP / CDS

RAP 용어 카드

BDEFBehavior Definition — 동작·검증·액션 선언
Determination저장 전 값을 자동으로 채우거나 파생
Validation저장 가능 여부를 검증해 실패 시 차단
Released APIC1 계약으로 안정성이 보장된 공개 API
AI 작성 메모: 약어(BDEF)는 앞면에 약어, 뒷면에 풀네임+한 줄 뜻을 함께 적는다.
