## 변경 사항

- 좌측 상단 'SAP 학습자료 홈'의 왼쪽 화살표를 제거했습니다.
- 홈 이동 의미가 명확하도록 집 모양 SVG 아이콘을 적용했습니다.
- 우측 상단 이전/다음 이동을 문자 화살표 대신 SVG 아이콘 버튼으로 변경했습니다.
- 관련 문서는 문서목차 탭 안에서만 표시합니다.
- 학습경로 탭에서는 관련 문서 링크를 제거했습니다.

## 유지 사항

- 우측 독립 Navigation 패널
- Navigation 접기 / 열기 버튼
- 현재 문서 카드
- 문서목차 / 학습경로 2개 탭
- 문서목차 Scroll Spy
