이미지 핫스팟 탐색

복잡한 화면이나 다이어그램 위에 인터랙티브 마커(핫스팟)를 배치하여, 마우스를 올릴 때만 상세 설명이 나타나게 합니다. 이를 통해 초기 화면의 인지 부하를 줄이고 능동적인 탐색을 유도할 수 있습니다.

실제 적용 예시

SAP GUI 개발 환경 구성 요소

처음 ABAP 에디터를 접하는 학습자에게 화면의 각 요소가 어떤 역할을 하는지 핫스팟으로 안내합니다. 이미지를 살펴보고 파란색 점에 마우스를 올려보세요.

예시 1 · ABAP Editor (SE38) 주요 기능

화면 구성 요소 인터랙티브 탐색

AI 작성 메모: 이미지 위에 텍스트를 무작정 박아넣으면 모바일 환경에서 글씨가 깨지거나 화면이 너무 복잡해집니다. 핫스팟 컴포넌트는 정보를 '선택적'으로 보여주어 정보의 밀도를 스마트하게 조절합니다.

예시 2 · ABAP Dictionary (SE11)

데이터베이스 테이블 구조 탐색

SE11에서 테이블을 생성할 때 필수적으로 입력해야 하는 영역을 확인합니다.
