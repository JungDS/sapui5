예시 1 · Report Event (Chapter 13 Lesson 2 원본)

DEFAULT vs INITIALIZATION

고정 기본값과 실행 시점 기본값을 고르는 기준

선언부 DEFAULT
언제 적합?항상 같은 값
예시DEFAULT '1000'
주의날짜·사용자별 값처럼 매번 계산되는 값엔 부적합
INITIALIZATION
언제 적합?실행 시점에 계산해야 하는 값
예시sy-datum, 이번 달 1일
주의화면 진입 준비 단계라 무거운 조회는 피함

매일 오늘 날짜를 기본 조회일로 쓰려면 고정 DEFAULT보다 INITIALIZATION이 자연스럽습니다.

AI 작성 메모: 좌우 카드의 행 항목(언제/예시/주의)을 동일하게 맞추면 같은 축으로 비교돼 차이가 또렷하다.

예시 2 · ALV 출력

Classic WRITE vs SALV

목록 출력 방식 비교

WRITE (Classic)
화면줄 단위 텍스트 직접 출력
기능정렬·필터·합계 직접 구현
유지보수레이아웃 바뀌면 코드 수정 큼
SALV
화면표준 그리드 자동 렌더링
기능정렬·필터·합계 툴바 기본 제공
유지보수필드 카탈로그 자동, 변경 쉬움
AI 작성 메모: 구식/현대식 비교는 "유지보수" 행을 꼭 넣어 왜 현대식을 권하는지 근거를 남긴다.
