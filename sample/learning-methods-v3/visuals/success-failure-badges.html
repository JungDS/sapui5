AI 작성 메모: 표의 "검증" 열을 배지로 채우면 통과/실패 행이 색으로 즉시 구분된다.

예시 2 · Open SQL (sy-subrc)

조회 결과에 따른 sy-subrc

SELECT 이후 시스템 필드 상태

조회 결과sy-subrc의미
1건 이상0조회 성공, 결과 존재
0건4조건에 맞는 행 없음(정상 결과일 수 있음)

sy-subrc = 4는 덤프가 아닙니다. 안내 메시지로 처리해 빈 화면 오해를 막습니다.

AI 작성 메모: sy-subrc는 "0=성공/4=없음"을 배지로 고정하면 초보자가 시스템 필드 값을 직관적으로 읽는다.

예시 3 · 권한 검사

AUTHORITY-CHECK 결과 배지

권한 객체 검사 분기

사용자권한처리
정훈영 (SD)있음 (subrc 0)조회 진행
외부 사용자없음 (subrc 4)MESSAGE E로 차단
AI 작성 메모: 권한 주제는 "있음/없음"을 배지로 보여주고, 없음일 때의 차단 동작을 반드시 함께 적는다.
