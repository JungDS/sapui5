현재 행 강조

LOOP·READ·이진 탐색에서 "지금 처리 중인 행"을 초록 강조선으로 표시해, 포인터가 어디를 가리키는지 시각화합니다. 추상적인 인덱스(sy-tabix)를 구체적인 위치로 바꿔줍니다.

Internal Table 적용포인터 위치 표시

실제 적용 예시 3

같은 수단을 세 가지 행 탐색에 적용

예시 1 · Internal Table — LOOP

LOOP 중 현재 행 (sy-tabix = 2)

반복문이 두 번째 행을 처리하는 순간

sy-tabix이름부서
1정훈영SD
2 ◀ 현재김지현FI
3박서우MM

초록 강조선이 Work Area로 복사돼 처리 중인 행을 가리킵니다.

AI 작성 메모: 반복 단계를 캡처처럼 한 장씩 보여주면 sy-tabix 증가가 위치 이동으로 체감된다.

예시 2 · Internal Table — READ TABLE

READ WITH KEY 매칭 행

READ TABLE lt WITH KEY empno = '3000'

사원번호이름
1000정훈영
2000김지현
3000 ◀ 매칭이민수

조건에 맞는 첫 행을 찾으면 sy-subrc = 0, Work Area에 그 행이 담깁니다.

AI 작성 메모: READ는 "찾은 한 행"을 강조해, LOOP의 "순차 이동"과 다른 일회성 탐색임을 대비시킨다.

예시 3 · Internal Table — BINARY SEARCH

이진 탐색 범위 좁히기

정렬된 테이블에서 중간값부터 비교 (목표: 4000)

인덱스값판정
11000범위 밖(아래)
22000범위 밖(아래)
3 ◀ 중간3000목표보다 작음 → 오른쪽 탐색

매 비교마다 후보가 절반으로 줄어 빠릅니다. 단, 사전 SORT가 필수입니다.

AI 작성 메모: 알고리즘은 "현재 비교 행(초록)"과 "다음 후보(노랑)"를 함께 표시해 좁혀가는 과정을 보인다.
