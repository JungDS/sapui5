드래그 앤 드롭 퀴즈

카드를 알맞은 순서 칸으로 끌어다 놓으면 정답 여부에 따라 칸이 초록/빨강으로 바뀌고, 모두 맞히면 축하 효과가 나타납니다. 배치한 카드를 클릭하면 다시 회수됩니다. 순서·분류·매칭 회수에 적합합니다.

원본: Chapter 13 Lesson 1 (이벤트 순서 맞추기) 드래그 → 즉시 채점 정답 시 컨페티

실제 적용 예시 3

같은 수단을 세 가지 ABAP 순서 문제에 적용

예시 1은 Chapter 13 Lesson 1의 이벤트 카드 순서 맞추기를 그대로 이식했습니다.

예시 1 · Report Event (Chapter 13 Lesson 1 원본)

리포트 이벤트 생명주기 순서

Q. 프로그램 호출부터 최종 출력까지, 리포트 전체 생명주기 순서를 채우세요.
1단계 (메모리 로드)
2단계 (화면 초기화)
3단계 (메인 쿼리)
4단계 (출력 마감)
드래그할 이벤트 블록 카드
START-OF-SELECTION
INITIALIZATION
LOAD-OF-PROGRAM
END-OF-SELECTION
AI 작성 메모: 단순 암기보다 카드를 직접 배열하게 하면 능동적 회수가 일어난다. 오답 피드백에 비유 힌트를 넣으면 재시도 동기가 생긴다.

예시 2 · Open SQL

SELECT 문 절(clause) 작성 순서

Q. ABAP SQL 한 문장에서 절이 등장하는 순서대로 채우세요.
1 (가져올 컬럼)
2 (조회 대상)
3 (필터)
4 (결과 담기)
드래그할 절 카드
WHERE
INTO TABLE
SELECT
FROM
AI 작성 메모: 구문 작성 순서가 헷갈리는 주제(SQL 절, OPEN/FETCH/CLOSE)는 카드 배열로 손에 익힌다.
