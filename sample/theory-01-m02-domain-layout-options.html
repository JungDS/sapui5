THEORY-01-M02 section 2 design options

Domain 설계의 네 칸 대안 샘플

현재 4개 카드가 한 줄에 모두 배치되어 답답하게 보이는 문제를 줄이기 위한 선택지입니다. 세 안 모두 가로 스크롤 없이 반응형으로 줄어듭니다.

실제 Lesson에 적용할 때는 선택한 안의 HTML 구조를 THEORY-01-M02 2번 섹션에 넣고, 필요한 CSS만 assets/abap-lesson-viewer.css로 옮기면 됩니다.
Option A

2x2 판단 보드

한 줄 4칸 대신 2열 2행으로 넓이를 확보합니다. 기존 카드형 UI와 가장 가깝고 적용 비용이 낮습니다.

T

Data Type

질문값의 종류는?
예CHARNUMCDATSCURR
판단계산할 숫자인지, 코드처럼 보이는 문자인지 구분한다.
L

Length

질문저장 가능한 최대 자릿수는?
예항공사 코드 CHAR 3 사번 NUMC 8
판단실제 업무 코드 길이를 확인한 뒤 정한다.
O

Output Length

질문화면·리스트 표시 폭은?
예날짜처럼 내부 길이와 표시 폭이 달라질 수 있다.
판단저장 길이와 같은 값이라고 단정하지 않는다.
F

Fixed Value

질문허용값이 작고 고정적인가?
예YNABC
판단값이 많거나 자주 늘면 별도 테이블 쪽을 검토한다.

추천 상황: 현재 디자인의 익숙함은 유지하되, 카드 폭만 넓혀 읽기 피로를 줄이고 싶을 때.
